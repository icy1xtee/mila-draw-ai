# mac — MacBook Air 13" M4, 24 ГБ

Локальная работа на Mac. Почему роли распределены именно так, объясняет
[.claude/research/01-hardware.md](../.claude/research/01-hardware.md).

## Роль

**Делаем здесь:**

- черновики и превью идей — быстрые модели (Anima Turbo);
- точечные правки: выделил область → перерисовал;
- правки по инструкции (FLUX 3 Image Klein) — особенно если на MSI окажется RTX 4050 6 ГБ;
- рисование в Krita, где генерация идёт на ComfyUI на MSI по локальной сети;
- **проверку цвета** финальных картинок: экран Katana покрывает ≈ 51 % sRGB.

**Не делаем:** длинные пачки и многочасовое обучение LoRA. Air без вентилятора и под долгой
нагрузкой сбрасывает частоты; одна картинка здесь — это минуты, а не секунды.

## Что ставим

| Что                                                                       | Зачем                                                                                              |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [Draw Things](https://drawthings.ai) (App Store, бесплатно)               | основной генератор на Mac: свой движок на Metal, быстрее ComfyUI. Inpaint, правки по инструкции, при нужде обучение LoRA |
| [Krita](https://krita.org) 5.3.x + [Krita AI Diffusion](https://github.com/Acly/krita-ai-diffusion) **1.53** | холст для правок «как художник». Сервер — ComfyUI на MSI. Не брать 1.54-pre для Krita 6: «known to perform poorly on macOS» |
| (по желанию) [mflux](https://github.com/mflux-community/mflux)            | CLI на MLX, если понадобятся скрипты                                                               |

## Модели в Draw Things

| Модель                         | Вариант                                         | Для чего                                                  |
| ------------------------------ | ----------------------------------------------- | --------------------------------------------------------- |
| Anima Turbo 1.0                | 8-bit S                                         | быстрые черновики фонов и персонажей                      |
| Anima Aesthetic 1.1            | 8-bit S                                         | основная Anima: фоны                                      |
| WAI-Illustrious-SDXL v17.0     | FP16, импорт `.safetensors` с [Civitai](https://civitai.com/models/827184) | спрайты; вместе с нашими LoRA, когда они появятся. Тот же файл, что на MSI |
| FLUX.3 [klein] 5.6B            | 8-bit S                                         | генерация и правки по инструкции, работа с референсами    |
| Qwen-Image 2.1 (позже)         | 4-bit                                           | только для некоммерческих экспериментов (лицензия)        |

На M4 выбирать варианты **8-bit S**: Draw Things ускоряет их на M4. «Exact» (полная точность)
не нужен. Все четыре модели вместе с текстовыми энкодерами занимают ≈ 21 ГБ.

## Настройки Mac

- Генерировать от сети.
- Если модели не хватает памяти GPU: `sudo sysctl iogpu.wired_limit_mb=20480`. Действует до
  перезагрузки; macOS нужно оставить хотя бы 4 ГБ.

## Генерация из терминала: API Draw Things

Draw Things → Advanced → **API Server**: HTTP, порт 7860, localhost. Пока приложение открыто и
сервер включён, генерировать можно без интерфейса. Так идут замеры и сравнение моделей, так же
генерирует Claude Code.

```sh
python3 mac/scripts/dt_generate.py mac/scripts/smoke.json
```

- [`scripts/dt_generate.py`](scripts/dt_generate.py) — системный `python3`, без зависимостей.
  Читает файл прогона, рисует каждую картинку через `POST /sdapi/v1/txt2img` и кладёт результат
  в `content/` по назначению: тесты — в `content/benchmarks/<дата>-<прогон>/`, работа — в
  `content/generated/<дата>/<назначение>/`. Устройство `content/` и правила — в
  [.claude/develop/mac/content.md](../.claude/develop/mac/content.md). В папке прогона:
  - `<модель>_<промпт>_<seed>.png` и рядом `.json` — параметры, время, пиковая память Draw
    Things и рост свопа. Пик памяти не учитывает веса, отображённые с диска, поэтому
    признак «не влезает» — рост свопа;
  - `log.jsonl` — те же записи, по строке на картинку, плюс время загрузки каждой модели.

  Готовые картинки пропускает, поэтому прерванный прогон продолжается с места остановки.
  Флаги: `--force` — перерисовать готовые, `--models a,b` — только эти модели, `--out` — другая
  папка (например, продолжить вчерашний прогон).
- [`scripts/models.json`](scripts/models.json) — настройки моделей: файл, шаги, CFG, сэмплер,
  shift, рекомендованный негатив и quality-теги. Значения взяты из рекомендаций Draw Things
  (community-models) и автора WAI, ссылка на источник — в поле `source`. Блок `base` — общие
  параметры всех запросов. Он явно выключает LoRA, hires fix, апскейлер и рефайнер, иначе они
  могли бы прийти из текущего состояния приложения.
- Файл прогона, пример — [`scripts/smoke.json`](scripts/smoke.json). Поля: `name`, `purpose`
  (`benchmarks`, `drafts`, `backgrounds`, `sprites`, `edits` — от него зависит папка),
  `models` (ключи из models.json), `seeds`, `prompts`. У каждого промпта:
  - `id`;
  - `width` и `height`, кратные 64 — другой размер Draw Things молча округлит, скрипт такой не
    пропустит;
  - `prompt` — одна строка на все модели или словарь по семейству моделей: `anima`,
    `illustrious`, `flux`;
  - необязательный `negative` — дописывается к негативу модели.

Что выяснилось про API:

- модель задаётся в каждом запросе полем `model` (имя файла), в приложении её переключать не
  нужно; несуществующую модель API отвергает с ошибкой 422;
- параметры, которых нет в запросе, Draw Things, судя по `GET /sdapi/v1/options`, берёт из
  текущих настроек приложения — поэтому блок `base`;
- seed воспроизводится: тот же запрос даёт ту же картинку;
- первый запрос после смены модели дольше — модель загружается. Скрипт сначала делает разогрев в
  512² и пишет его время отдельно;
- сэмплеры называются как в Draw Things («DDIM Trailing», «Euler a», …). Список приходит в
  ответе на запрос с неверным `sampler`;
- каждая генерация, и через API тоже, остаётся ещё и в истории проекта Draw Things, ≈ 1,7 МБ на
  картинку. Чистит её [`scripts/dt_clean.sh`](scripts/dt_clean.sh): без `--yes` показывает
  список, с `--yes` переносит проекты в Корзину, если Draw Things закрыт. Подробнее — в
  [content.md](../.claude/develop/mac/content.md#копии-в-самом-draw-things-и-очистка).

## Krita → ComfyUI на MSI

Krita AI Diffusion → Settings → Connection → Custom Server → `http://<IP MSI>:8188`. На MSI
ComfyUI должен слушать сеть, и на нём должны стоять ноды, которые требует плагин (см.
[msi/README.md](../msi/README.md) и [документацию плагина](https://docs.interstice.cloud)).

## Что класть в эту папку

- **Да:** скрипты, настройки моделей и файлы прогонов (`scripts/`), замеры скорости
  ([benchmarks.md](benchmarks.md)), заметки по настройке Mac.
- **Нет:** веса моделей (Draw Things хранит их у себя). Картинки, референсы и датасеты лежат в
  `content/` в корне репо, вне git.
