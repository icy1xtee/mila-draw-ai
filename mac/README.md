# mac — MacBook Air 13" M4, 24 ГБ

Локальная работа на Mac. Почему роли распределены именно так, объясняет
[.claude/research/01-hardware.md](../.claude/research/01-hardware.md).

## Роль

**Делаем здесь:**

- черновики и превью идей — быстрые модели (Anima Turbo);
- точечные правки: выделил область → перерисовал;
- правки по инструкции (FLUX 3 Image Klein) — особенно если на MSI окажется RTX 4050 6 ГБ;
- рисование в Krita, где генерация идёт на ComfyUI на MSI по локальной сети;
- **проверку цвета** финальных картинок: экран Katana покрывает ≈ 51 % sRGB.

**Не делаем:** длинные пачки и многочасовое обучение LoRA. Air без вентилятора и под долгой
нагрузкой сбрасывает частоты; одна картинка здесь — это минуты, а не секунды.

## Что ставим

| Что                                                                       | Зачем                                                                                              |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [Draw Things](https://drawthings.ai) (App Store, бесплатно)               | основной генератор на Mac: свой движок на Metal, быстрее ComfyUI. Inpaint, правки по инструкции, при нужде обучение LoRA |
| [Krita](https://krita.org) 5.3.x + [Krita AI Diffusion](https://github.com/Acly/krita-ai-diffusion) **1.53** | холст для правок «как художник». Сервер — ComfyUI на MSI. Не брать 1.54-pre для Krita 6: «known to perform poorly on macOS» |
| (по желанию) [mflux](https://github.com/mflux-community/mflux)            | CLI на MLX, если понадобятся скрипты                                                               |

## Модели в Draw Things

| Модель                                       | Вариант            | Для чего                                                        |
| -------------------------------------------- | ------------------ | --------------------------------------------------------------- |
| Anima                                        | Turbo, Aesthetic   | быстрые черновики фонов и персонажей                            |
| Illustrious-чекпойнт (тот же файл, что на MSI) | импорт `.safetensors` | спрайты; вместе с нашими LoRA, когда они появятся            |
| FLUX 3 Image Klein                           | 8-bit              | правки по инструкции, работа с референсами                      |
| Qwen-Image 2.1                               | 4-bit              | только для некоммерческих экспериментов (лицензия)              |

На M4 выбирать 8-битные варианты: с апреля 2026 Draw Things ускоряет их на M4.

## Настройки Mac

- Генерировать от сети.
- Если модели не хватает памяти GPU: `sudo sysctl iogpu.wired_limit_mb=20480`. Действует до
  перезагрузки; macOS нужно оставить хотя бы 4 ГБ.

## Krita → ComfyUI на MSI

Krita AI Diffusion → Settings → Connection → Custom Server → `http://<IP MSI>:8188`. На MSI
ComfyUI должен слушать сеть, и на нём должны стоять ноды, которые требует плагин (см.
[msi/README.md](../msi/README.md) и [документацию плагина](https://docs.interstice.cloud)).

## Что класть в эту папку

- **Да:** настройки генерации Draw Things (копируются как JSON), замеры скорости

- **Нет:** веса моделей (Draw Things хранит их у себя), сгенерированные картинки, датасеты.
