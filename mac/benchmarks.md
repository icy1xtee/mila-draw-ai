# Замеры скорости: MacBook Air M4, 24 ГБ

Draw Things 26.1020.0, генерация через API — скрипт [scripts/dt_generate.py](scripts/dt_generate.py),
настройки моделей — [scripts/models.json](scripts/models.json). Картинки и сырые данные лежат в
`content/benchmarks/<дата>-<прогон>/`, вместе с `log.jsonl`.

«На шаг» — время одного шага сэмплера. При CFG > 1 шаг считается в два прохода, поэтому он
дороже.

## Предварительно: проверочный прогон, 02.11.2026 (`2026-11-02-smoke`)

Одна картинка 1024² на модель. Модели шли подряд, почти без перерывов, так что Mac всё время был
горячим. Anima — от батареи, остальные — от сети. Это **нижняя граница скорости**, не итог.

| Модель                        | Шаги, CFG | Загрузка + разогрев 512² | 1024²            | На шаг | Пик Draw Things | Рост свопа |
| ----------------------------- | --------- | ------------------------ | ---------------- | ------ | --------------- | ---------- |
| Anima Turbo 1.0 (8-bit S)     | 8, 1      | 13 с                     | 56 с             | 7 с    | 1,8 ГБ          | 0          |
| Anima Aesthetic 1.1 (8-bit S) | 30, 4     | 105 с                    | 704 с (11,7 мин) | 23 с   | 1,9 ГБ          | 0          |
| WAI-Illustrious v17 (FP16)    | 28, 6     | 56 с                     | 245 с (4,1 мин)  | 8,7 с  | 6,1 ГБ          | 0          |
| FLUX.3 [klein] 5.6B (8-bit S) | 16, 1     | 81 с                     | 455 с (7,6 мин)  | 28 с   | 3,1 ГБ          | 0          |

Ещё два отдельных запроса на Anima Turbo, 8 шагов: 512² — 14 с, 1536×832 — 70 с.

Что видно уже сейчас:

- **Всё влезает в 24 ГБ без свопа**, даже при открытых VS Code и браузере.
- Пик по `footprint` не учитывает веса, которые Draw Things читает с диска через отображение в
  память. У Anima пик 1,8 ГБ при файле 2,3 ГБ, у FLUX — 3,1 ГБ при 5,7 ГБ модели и 4,4 ГБ
  энкодера. Поэтому признак «не влезает» — рост свопа, а не этот пик.
- Оценка из ресерча «≈ 2 мин на Anima Turbo» оказалась пессимистичной: на деле ≈ 1 мин. Зато
  Anima Aesthetic (30 шагов при CFG 4) и FLUX — 8–12 минут на картинку, а не «1,5–3 мин».

## Полные замеры — ждут запуска

Mac от сети, перед стартом остыл. Каждый прогон занимает Mac целиком.

1. **Троттлинг** — [scripts/bench-throttle.json](scripts/bench-throttle.json): 10 × Anima Turbo
   1024² подряд с холодного Mac, ≈ 10–15 мин. По времени картинок видно, с какой начинается
   замедление и насколько оно сильное.
2. **Скорость моделей** — [scripts/bench.json](scripts/bench.json): каждая модель в 1024² и
   1600×896 (16:9, кратно 64), по одной картинке, ≈ 1–1,5 ч. Прогон идёт сразу за первым, так
   что это скорость прогретого Mac — с такой же пойдёт сравнение моделей.

```sh
python3 mac/scripts/dt_generate.py mac/scripts/bench-throttle.json
python3 mac/scripts/dt_generate.py mac/scripts/bench.json
```
