# web-interface — локальный веб-интерфейс проекта

Заведено 07.11.2026. Пока только задумка, кода нет.

## Зачем

Одна страница в браузере, через которую с генерацией работают Павел и его девушка, без
терминала и без ComfyUI:

1. **Передача `content/`** между машинами: рисунки, референсы, результаты прогонов. Сейчас это
   основной способ делиться картинками — флешки и облако не используем.
2. **Управление генерацией** (позже):
   - модель и все параметры: размер, шаги, CFG, сэмплер, seed;
   - промпт из карточек мира, мест и персонажей ([.claude/vibe-description/](../.claude/vibe-description/README.md));
   - LoRA: подключить, отключить, выбрать, задать силу;
   - референсы для edit-моделей;
   - очередь, история, просмотр результатов с их `.json`.

## Как устроено (черновик)

- Поднимается локально на одной из машин и открывается с другой по домашней сети. Скорее всего
  на MSI: там ComfyUI и основная генерация, а `content/` нужен рядом с ним. Окончательно —
  когда начнём.
- Генерирует через API ComfyUI (на MSI) — те же файлы прогонов и `models.json`, что у скриптов
  машин.
- Картинки кладёт и читает по правилам [content.md](../.claude/develop/mac/content.md).
- Только домашняя сеть: в интернет не выставлять, как и ComfyUI.

- Нужен ли вход по паролю внутри домашней сети.
- Стек: решим, когда начнём; предпочтительно без тяжёлой сборки.
