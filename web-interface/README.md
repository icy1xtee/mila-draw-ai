# Mila Draw AI

Простой инструмент для Милы: прикрепить свою картинку и попросить модель её доработать, или
нарисовать с нуля по промпту. Работает на MSI, открывается с ноутбука, планшета или телефона в
домашней сети. Порядок работ — в [плане MSI](../.claude/develop/msi/plan.md), шаг 6.

Статус (08.11.2026): **MVP**. Финальные арты здесь не генерируем: это помощник художника.
Контекста новеллы в инструменте нет совсем: ни карточек, ни предпромптов, ни сравнений со
стилем игры.

## Что умеет

**С картинкой.** Мила прикрепляет одну или несколько картинок (до 4):

1. Claude сразу описывает каждую: что изображено (по-русски), теги Danbooru о содержании и
   отдельно — о технике (`lineart`, `monochrome`, `sketch`…). Тег нажал — он ушёл в промпт,
   «＋ все теги» — все теги содержания сразу; повторно уже записанные не добавляются. Теги
   техники описывают исходник, а не желаемый результат, поэтому в «все теги» не входят:
   иначе промпт просит модель снова нарисовать чёрно-белый лайнарт.
2. Мила выбирает, что сделать:

   | Заготовка              | Что просит модель                                          |
   | ---------------------- | ---------------------------------------------------------- |
   | Чистовой скетч         | из наброска — чистые линии, детали, правка анатомии        |
   | Раскрасить             | лайнарт или набросок → цвет и шейдинг, рисунок тот же      |
   | Закончить иллюстрацию  | из цветного скетча — лайнарт, детали, шейдинг              |
   | Добавить рендер        | готовая иллюстрация — рендер, блики, мелкие детали         |
   | Персонаж по референсам | один персонаж из нескольких референсов                     |
   | Дизайн по фото         | персонаж по фото: собака → фурри, заколка → её вайб        |
   | Свой промпт            | ничего не добавляется                                      |

   Под заготовкой видно, какой текст она добавит к промпту.
3. Выбирает модель и пишет, что поменять (можно по-русски — кнопка «Перевести в промпт»).
4. «Нарисовать».

Как модель работает с картинкой:

- **FLUX 3 Klein** — все картинки как референсы (режим редактирования): модель видит их и
  делает новую по инструкции, рисунок и дизайн держит лучше всех. Любая заготовка «Что
  сделать» сама переключает на FLUX; две последние умеет только он.
- **Anima, WAI-Illustrious** — img2img по первой картинке. «Сила изменений» в настройках:
  меньше — ближе к исходной. По умолчанию — от заготовки (скетч 0,55, раскрасить 0,75,
  иллюстрация 0,5, рендер 0,35). Цвет на чистый лайнарт при силе ниже ≈ 0,7 почти не ложится,
  а выше начинает плыть дизайн (проверено 08.11 на Anima Turbo) — раскрашивать лучше FLUX.
  Команды вроде «add colors» модели на тегах не понимают: им нужно описание результата.

**Без картинки.** Модель, «Что рисуем» — Персонаж / Фон / Другое (предпромпт и размер),
галочка «Белый фон» у персонажа, промпт, «Нарисовать».

**Подсказка по модели** — кнопка «?» рядом с выбором модели: как модель работает без
картинки и с картинкой, как писать промпт, пример (вставляется в промпт кнопкой), работает ли
негатив, скорость. Тексты — [help.json](help.json), правятся без перезапуска сервера
(страницу обновить).

**Настройки модели** — окно по кнопке «Настройки»: сколько картинок (1–4), размер (без
картинки), сила изменений (img2img), шаги, CFG, сэмплер, планировщик, seed, теги качества,
LoRA (если есть в ComfyUI). Запоминаются в браузере для каждой модели, «Сбросить» — к
стандартным.

**Помощник промпта** переводит текст в промпт под модель: теги Danbooru для Anima и WAI,
английские фразы для FLUX (картинки — как `<ref_image_0>`, если текст о них говорит). Только
перевод: ничего не добавляет, не заменяет и не комментирует; незнакомое имя оставляет как
есть. «Вернуть мой текст» — откатить.

**История задачи** — справа (на телефоне ниже): прикреплённые картинки с описанием и
генерации с промптом, новые сверху. Картинка крупно: листать, «Скачать», «В работу»
(прикрепить к следующей генерации), «Повторить настройки».

**Прогресс** — полоса сверху на всех экранах и карточка в задаче: этап, «≈ 25 с», отмена.

## Устройство

| Что       | Как                                                                                       |
| --------- | ----------------------------------------------------------------------------------------- |
| Где живёт | MSI, рядом с ComfyUI                                                                      |
| Сервер    | Python 3.13, FastAPI + uvicorn, окружение через `uv`                                      |
| Страница  | HTML + CSS + JS без сборки и без CDN                                                      |
| ComfyUI   | только `127.0.0.1:8188`, с ним говорит один сервер                                        |
| Сеть      | порт **8000**, брандмауэр — только частная сеть. В интернет не выставлять                  |
| Вход      | общий пароль из `.env` (не в git)                                                          |
| Модели    | [msi/catalog/models.json](../msi/catalog/models.json), LoRA — [loras.json](../msi/catalog/loras.json) |
| Заготовки | [presets.json](presets.json): что рисуем, что сделать с картинкой, размеры                 |
| Claude    | `claude -p --restricted` — описание картинки и помощник промпта                           |

```
web-interface/
├── README.md            этот файл
├── presets.json         заготовки и размеры
├── help.json            тексты подсказки «?» по моделям
├── pyproject.toml       зависимости сервера (uv)
├── start.bat            запуск двойным щелчком — то же, что studio start
├── .env.example         образец настроек (.env — не в git)
├── server/
│   ├── app.py           маршруты API и раздача страницы
│   ├── config.py        пути и настройки
│   ├── catalog.py       модели, LoRA, заготовки, сборка промпта
│   ├── graphs.py        графы ComfyUI: text-to-image, img2img, FLUX с референсами
│   ├── comfy.py         клиент ComfyUI
│   ├── jobs.py          очередь, прогресс, оценка времени
│   ├── tasks.py         задачи в content/tasks/, превью
│   └── claude.py        описание картинки, помощник промпта
├── claude/              инструкции для Claude: describe.md, prompt-helper.md
├── static/              index.html, app.css, app.js
└── .cache/              превью (не в git)
```

Сборка промпта (`catalog.assemble`): теги качества модели (галочка в настройках) →
заготовка → «Белый фон» → промпт Милы → триггеры LoRA. Тег, который оказался в промпте,
убирается из негатива (например, `sketch` из негатива WAI для «Чистового скетча»).

FLUX с референсами — граф из официального шаблона ComfyUI
`image_flux3_klein_distilled_image_edit.json`: картинки через `ReferenceMultiLatent` (≈ 1 МП),
размер результата — по первой картинке, у референсных заготовок — 9:16.

## Задачи: `content/tasks/`

```
content/tasks/2026-11-08-devochka-s-zakolkoy/
├── task.json            название, когда создана
├── zakolka.jpg          прикреплённая картинка
├── zakolka.json         {"type": "upload", "time", "original", "analysis": {description, tags}}
├── flux3-klein_123.png  результат
└── flux3-klein_123.json {"type": "generated", "job", "mode", "model", "preset", "prompt",
                          "inputs", "settings", "seed", "seconds", "positive_final", "payload"}
```

Прикреплённые картинки хранятся повёрнутыми по EXIF, прозрачность — на белом, не больше
2048 px по длинной стороне; фото остаются JPEG, остальное — PNG.

**Удаление.** Задачу целиком удаляет человек — кнопка «Удалить» на странице задачи, после
подтверждения: папка со всеми картинками и превью стирается насовсем, корзины нет. Пока в
задаче идёт генерация, сервер удалить не даст. Отдельные картинки — пока вручную в
`content/tasks/`.

## Запуск и остановка

Из корня репо (в PowerShell — с `.\` впереди):

| Команда                                    | Что делает                         |
| ------------------------------------------ | ---------------------------------- |
| `studio start`                             | запустить ComfyUI и Mila Draw AI   |
| `studio stop`                              | остановить оба                     |
| `studio restart`                           | перезапустить оба                  |
| `studio start comfy` / `studio stop comfy` | только ComfyUI (и `restart comfy`) |
| `studio start web` / `studio stop web`     | только Mila Draw AI (и `restart web`) |
| `studio status`                            | что запущено и по каким адресам    |
| `studio logs web` / `studio logs comfy`    | смотреть лог, Ctrl+C — выйти       |

- Сервисы работают в фоне без окон и не гаснут, если закрыть терминал.
- `studio start` ждёт, пока сервисы ответят, и печатает адрес для телефона и Mac:
  `http://<IP MSI>:8000` — набирать целиком, с `http://` и `:8000`.
- Логи — `logs\comfy.log` и `logs\web.log` в корне репо (не в git).
- Логика — [msi/scripts/studio.ps1](../msi/scripts/studio.ps1).

### Первый запуск (один раз)

1. **Пароль** — скопировать `.env.example` в `.env`, вписать `STUDIO_PASSWORD`.
2. **Брандмауэр** — PowerShell от администратора:

   ```powershell
   New-NetFirewallRule -DisplayName "mila-draw-ai web interface" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
   ```

3. **Постоянный адрес** — резерв IP для MSI в роутере.

Нужно на машине: ComfyUI с моделями из каталога, `uv`, Claude Code CLI (`claude` в PATH, вход
выполнен). Без Claude всё работает, кроме описания картинок и перевода в промпт.

## API

| Метод и путь                   | Что                                                         |
| ------------------------------ | ----------------------------------------------------------- |
| `GET /api/session`, `POST /api/login` | вход по паролю → cookie                              |
| `GET /api/catalog`             | модели, заготовки, размеры, LoRA, сэмплеры, есть ли Claude  |
| `GET /api/status`              | очередь: этап, прогресс, сколько осталось                   |
| `GET/POST /api/tasks`, `GET/PATCH/DELETE /api/tasks/{id}` | задачи: список, новая, история, переименовать, удалить |
| `POST /api/tasks/{id}/uploads` | прикрепить картинки (multipart), Claude начинает описывать  |
| `POST /api/describe`           | описать картинку (результат «в работу», повтор после ошибки) |
| `POST /api/prompt-help`        | текст → промпт под модель                                   |
| `POST /api/jobs`, `DELETE /api/jobs/{id}` | генерация и отмена                               |
| `GET /files/{путь}`, `GET /thumbs/{путь}` | картинка из `content/tasks/` и её превью         |
