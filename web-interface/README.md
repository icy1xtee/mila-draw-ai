# Mila Draw AI

Простой инструмент для Милы: прикрепить свою картинку и попросить модель её доработать, или
нарисовать с нуля по промпту. Работает на MSI, открывается с ноутбука, планшета или телефона в
домашней сети. Порядок работ — в [плане MSI](../.claude/develop/msi/plan.md), шаг 6.

Статус (08.11.2026): **MVP**. Финальные арты здесь не генерируем: это помощник художника.
Контекста новеллы в инструменте нет совсем: ни карточек, ни предпромптов, ни сравнений со
стилем игры.

## Что умеет

**Задачи** — на главной карточки (на телефоне по одной в ряд, на компьютере по шесть), превью
целиком, с полями по краям. Новая — поле названия и «＋». В задаче вверху «Задачи» (назад), ✎ —
переименовать (или нажать на название), корзина — удалить; название — отдельной строкой.

**Задача** — папка для одной работы. Название можно не писать: тогда задача получит имя
`unknown_1`, `unknown_2`… (следующий номер после самого большого).

**С картинкой.** Мила прикрепляет одну или несколько картинок (до 4):

1. Claude сразу описывает каждую: что изображено (по-русски), теги Danbooru о содержании и
   отдельно — о технике (`lineart`, `monochrome`, `sketch`…). Тег нажал — он ушёл в промпт,
   «＋ все теги» — все теги содержания сразу; повторно уже записанные не добавляются. Теги
   техники описывают исходник, а не желаемый результат, поэтому в «все теги» не входят:
   иначе промпт просит модель снова нарисовать чёрно-белый лайнарт.
2. Мила выбирает, что сделать. Заготовки — карточки с описанием, что берут и что дают:

   | Заготовка             | Берёт → даёт                                                                  | Сила (img2img) |
   | --------------------- | ----------------------------------------------------------------------------- | -------------- |
   | Чистовой скетч        | черновой ч/б набросок → чистый законченный скетч, анатомия поправлена          | 0,55           |
   | Раскрасить            | лайнарт или чистовой скетч → цвет и мягкие тени, рисунок тот же               | 0,75           |
   | Улучшить иллюстрацию  | цветной скетч / незаконченная работа → готовая: лайнарт, анатомия, детали, свет | 0,6          |
   | Полировка             | почти готовая иллюстрация → блики, рефлексы, переходы; не перерисовывает      | 0,3            |
   | Дизайн по фото        | фото предмета → персонаж по его мотивам; «Один вариант» или «Мозговой штурм»  | —              |
   | Свой промпт           | ничего не добавляется                                                         | —              |

   «Улучшить» меняет заметно (это доводка), «Полировка» — едва заметно (это финальный лоск).
   Под заготовкой видно, какой текст она добавит к промпту. Тексты — [presets.json](presets.json).
3. Выбирает модель, пишет пожелание в «ИИ-помощник» или сразу промпт.
4. «Нарисовать».

Как модель работает с картинкой:

- **FLUX 3 Klein** — все картинки как референсы (режим редактирования): модель видит их и
  делает новую по инструкции, рисунок и дизайн держит лучше всех. Любая заготовка «Что
  сделать» сама переключает на FLUX; «Дизайн по фото» умеет только он.
- **Anima, WAI-Illustrious** — img2img по первой картинке. «Сила изменений» в настройках:
  меньше — ближе к исходной, по умолчанию — от заготовки (таблица выше). Цвет на чистый
  лайнарт при силе ниже ≈ 0,7 почти не ложится, а выше начинает плыть дизайн (проверено 08.11
  на Anima Turbo) — раскрашивать лучше FLUX. Команды вроде «add colors» модели на тегах не
  понимают: им нужно описание результата.

**Мозговой штурм** (внутри «Дизайн по фото»). FLUX по фото держится близко к исходнику, а
img2img других моделей просто перерисовывает картинку в своём стиле — для поиска идей ни то,
ни другое. Поэтому:

1. Claude смотрит фото и придумывает 3, 4 или 6 разных персонажей (можно дать пожелание:
   «девочка-подросток, фэнтези»). У каждой идеи — название, описание по-русски, теги для
   моделей на тегах и фразы для FLUX.
2. Мила снимает галочки с лишних идей и выбирает модели (по умолчанию Anima Turbo,
   WAI-Illustrious, FLUX).
3. «Нарисовать: 4 идеи × 3 модели = 12» — каждая идея рисуется в каждой модели **по описанию,
   без фото** (заготовка «Персонаж», 9:16, белый фон по галочке). Очередь идёт модель за
   моделью, чтобы каждая загружалась один раз.
4. В истории это один блок «Мозговой штурм» с подписями «идея · модель». Понравившуюся —
   открыть и «Доработать»: она заменяет фото в прикреплённых, дальше обычные заготовки.

Проверено 08.11: 3 идеи по фото питайи — 17 с, 2 идеи × 2 модели — 54 с.

**Без картинки.** Модель, «Что рисуем» — Без шаблона (по умолчанию: к промпту ничего не добавляется) / Персонаж / Фон (предпромпт и размер, у
каждого описание), галочка «Белый фон» у персонажа, промпт, «Нарисовать».

**ИИ-помощник** — поле над промптом. Мила пишет своими словами, что хочет получить, Claude
заполняет промпт (теги Danbooru для Anima и WAI, английские фразы для FLUX, `<ref_image_N>`
для картинок), негатив (если модель его понимает) и даёт короткую подсказку: какие настройки
поменять и почему, а если задаче явно лучше подходит другая заготовка или модель — говорит об
этом. Предложенные настройки (шаги, CFG, сила изменений, сколько картинок) ставятся кнопкой
«Применить». Содержание промпта — только из пожелания: помощник ничего не придумывает, не
заменяет и не выбрасывает; для img2img берёт ещё теги содержания из описания картинки (модели
нужен весь результат). Инструкция — [claude/assistant.md](claude/assistant.md).

**Промпт** — ✕ в углу поля очищает его одним касанием (так же у негатива и помощника).
«Вернуть как было» — откатить очистку, ответ помощника или вставленный пример.

**Подсказка по модели** — кнопка «?» рядом с выбором модели: как модель работает без
картинки и с картинкой, как писать промпт, пример (вставляется в промпт кнопкой), работает ли
негатив, скорость.

**LoRA** — блок под выбором модели. Показывает только LoRA, которые подходят к выбранной модели
(папка `loras/<семейство>/`), сгруппированные по типу: стиль, приём, одежда, эффект, детали,
качество, служебные. У каждой — что делает, «не для продажи», если автор запрещает продавать
картинки, и «Подробнее»: как использовать, чего не делать, сила, лицензия, ссылка на Civitai.
Включённая: ползунок силы, выбор варианта (если у LoRA несколько стилей на разных словах-ключах),
«В промпт добавится само: …» (слово-ключ сервер дописывает сам), слова по желанию кнопками и
«Поставить настройки автора» (сэмплер, планировщик, CFG, шаги из описания LoRA). Предупреждает,
если включено больше трёх LoRA или две стилевые сразу. Всё это — из
[msi/catalog/loras.json](../msi/catalog/loras.json); человеческая документация —
[msi/catalog/loras.md](../msi/catalog/loras.md) (и копия `README.md` рядом с файлами в
`models/loras/`). Новые файлы: `msi/scripts/lora_catalog.py scan` найдёт их на Civitai по хешу и
подготовит черновик записи, `… doc` пересоберёт документацию. Файл без записи всё равно виден — в
группе «Без описания».

**Настройки модели** — окно по шестерёнке рядом с выбором модели: сколько картинок (1–4), размер (без
картинки), сила изменений (img2img), шаги, CFG, сэмплер, планировщик, seed, теги качества,
LoRA (если есть в ComfyUI). Под каждой настройкой — что она делает и к чему приводит, и
отдельной строкой — стандарт для выбранной модели (из официальных workflow и карточек
моделей). Запоминаются в браузере для каждой модели, «Сбросить» — к стандартным.

**Hires fix** — в настройках моделей на тегах (Anima, WAI; без картинки и img2img): второй
проход, как в A1111/Forge. Картинка рисуется в обычном размере, увеличивается аниме-апскейлером
(×1,5 или ×2; апскейлер на выбор: `RealESRGAN_x4plus_anime_6B` — под аниме, стандарт, или `4x_foolhardy_Remacri` — сохраняет фактуру) и перерисовывается поверх с «Силой» ≈ 0,5 — так
получаются детали витринных картинок с Civitai. Шаги и CFG второго прохода — свои (у автора
WAI: 20 шагов, CFG 4,5). Итог не больше 6 Мп. Замеры, WAI 1024×1344: ×1,5 → 1536×2016 за
≈ 55 с, ×2 → 2048×2688 за ≈ 2–2,5 мин. Мозговой штурм рисует без него — быстрее.

**Вставить параметры** (кнопка «Вставить параметры» вверху задачи, или просто вставить текст в
поле промпта) — параметры генерации из Civitai («Copy generation data»), A1111 или Forge:

```
<промпт>
Negative prompt: <негатив>
Steps: 30, CFG scale: 7, Sampler: Euler a, Seed: 3524464997, Size: 1024x1344, Hires upscale: 2, …
```

Раскладывается по всем настройкам: модель (по имени файла; незнакомая SDXL-модель — Animagine,
Pony, NoobAI — заменяется на WAI), промпт и негатив, размер (кратно 64; заготовка — «Без шаблона»,
чтобы ничего не добавлялось), шаги, CFG, сэмплер (`Euler a` → `euler_ancestral`, `DPM++ 2M
Karras` → `dpmpp_2m` + `karras`), планировщик (`Automatic` → `karras` у DPM++, иначе
`normal`), seed, hires fix (увеличение, сила, шаги и CFG второго прохода), LoRA из
`<lora:имя:0.8>`, если такая есть в ComfyUI. Теги качества выключаются — они уже в промпте.
Под промптом — что перенесено и что нет (чужая модель, апскейлер, ADetailer, Clip skip,
отличный от модели). Промпт откатывается «Вернуть как было», настройки — «Сбросить» в окне
настроек. Проверено 08.11 на двух картинках WAI с Civitai.

**Промпты с Civitai.** Там почти всё сделано в A1111/Forge, где `[художник]` значит «слабее в
1,1 раза». В ComfyUI такого синтаксиса нет, поэтому при вставке в промпт (и ещё раз на
сервере) `[x]` становится `(x:0.91)`, `[[x]]` — `(x:0.83)`. `[a:b:0.5]` и `[a|b]` остаются как
есть: в ComfyUI им аналога нет. Повторить чужую картинку один в один всё равно не выйдет: шум
из seed A1111/Forge и ComfyUI считают по-разному — получится та же идея и композиция, но не
тот же кадр. Полные параметры картинки (размер, hires fix) — в API Civitai:
`https://civitai.com/api/generation/data?type=image&id=<номер картинки>`.

Тексты подсказок и пояснений — [help.json](help.json), правятся без перезапуска сервера
(страницу обновить). Помощник читает их же.

**История задачи** — справа (на телефоне ниже): прикреплённые картинки с описанием и
генерации с промптом, новые сверху. Картинка крупно: листать (стрелки, свайп), «Скачать»,
«Доработать» — прикрепить картинку к следующей генерации. «Все параметры» — модель, режим,
заготовка, размер (до и после hires fix), шаги, CFG, сэмплер, планировщик, seed, hires fix, LoRA с
силой и вариантом, итоговые промпт и негатив, время; ниже — тот же набор текстом в формате
Civitai / A1111 и кнопка «Скопировать параметры». Этот текст понимает «Вставить параметры» здесь,
на Civitai и в A1111/Forge: LoRA записаны как `<lora:имя:сила>`, вариант LoRA узнаётся по слову в
промпте, слово-ключ, уже стоящее в промпте, сервер второй раз не добавляет. Копирование по
домашней сети (http) идёт старым способом браузера — если не вышло, текст можно выделить вручную. Приближается сама картинка, а не
страница: двумя пальцами, двойным касанием или колёсиком мыши; приближенную можно двигать,
листание свайпом в это время выключено.

**Прогресс** — полоса сверху на всех экранах и карточка в задаче: этап, «≈ 25 с», отмена.

## Устройство

| Что       | Как                                                                                       |
| --------- | ----------------------------------------------------------------------------------------- |
| Где живёт | MSI, рядом с ComfyUI                                                                      |
| Сервер    | Python 3.13, FastAPI + uvicorn, окружение через `uv`                                      |
| Страница  | HTML + CSS + JS без сборки и без CDN                                                      |
| ComfyUI   | только `127.0.0.1:8188`, с ним говорит один сервер                                        |
| Сеть      | порт **8000**, брандмауэр — только частная сеть. В интернет не выставлять                  |
| Вход      | общий пароль из `.env` (не в git)                                                          |
| Модели    | [msi/catalog/models.json](../msi/catalog/models.json), LoRA — [loras.json](../msi/catalog/loras.json) |
| Заготовки | [presets.json](presets.json): что рисуем, что сделать с картинкой, размеры                 |
| Claude    | `claude -p --restricted` — описание картинки, ИИ-помощник, мозговой штурм                |

```
web-interface/
├── README.md            этот файл
├── presets.json         заготовки и размеры
├── help.json            тексты подсказки «?» по моделям
├── pyproject.toml       зависимости сервера (uv)
├── start.bat            запуск двойным щелчком — то же, что studio start
├── .env.example         образец настроек (.env — не в git)
├── server/
│   ├── app.py           маршруты API и раздача страницы
│   ├── config.py        пути и настройки
│   ├── catalog.py       модели, LoRA, заготовки, сборка промпта
│   ├── graphs.py        графы ComfyUI: text-to-image, img2img, FLUX с референсами, hires fix
│   ├── comfy.py         клиент ComfyUI
│   ├── jobs.py          очередь, прогресс, оценка времени
│   ├── tasks.py         задачи в content/tasks/, превью
│   └── claude.py        описание картинки, ИИ-помощник, мозговой штурм
├── claude/              инструкции для Claude: describe.md, assistant.md, brainstorm.md
├── static/              index.html, app.css, app.js
└── .cache/              превью (не в git)
```

Сборка промпта (`catalog.assemble`): теги качества модели (галочка в настройках) →
заготовка → «Белый фон» → промпт Милы → триггеры LoRA. Тег, который оказался в промпте,
убирается из негатива (например, `sketch` из негатива WAI для «Чистового скетча»). У моделей на
тегах веса A1111 `[x]` переводятся в `(x:0.91)`.

FLUX с референсами — граф из официального шаблона ComfyUI
`image_flux3_klein_distilled_image_edit.json`: картинки через `ReferenceMultiLatent` (≈ 1 МП),
размер результата — по первой картинке, у «Дизайн по фото» — 9:16.

## Задачи: `content/tasks/`

```
content/tasks/2026-11-08-devochka-s-zakolkoy/
├── task.json            название, когда создана
├── zakolka.jpg          прикреплённая картинка
├── zakolka.json         {"type": "upload", "time", "original", "analysis": {description, tags}}
├── flux3-klein_123.png  результат
└── flux3-klein_123.json {"type": "generated", "job", "mode", "model", "preset", "prompt",
                          "inputs", "settings", "seed", "seconds", "positive_final", "payload"}
```

У картинки из мозгового штурма в `.json` есть `"idea": {"batch", "n", "title", "description", "source"}`:
какая идея, из какого штурма и по какому фото. По `batch` история собирает штурм в один блок.

Прикреплённые картинки хранятся повёрнутыми по EXIF, прозрачность — на белом, не больше
2048 px по длинной стороне; фото остаются JPEG, остальное — PNG.

**Удаление.** Задачу целиком удаляет человек — кнопка «Удалить» на странице задачи, после
подтверждения: папка со всеми картинками и превью стирается насовсем, корзины нет. Пока в
задаче идёт генерация, сервер удалить не даст. **Отдельную картинку** (неудачную генерацию или
прикреплённую) — корзина в углу картинки в истории задачи, после подтверждения: удаляются картинка, её `.json` и
превью, история перерисовывается без неё. Картинку, которая нужна идущей сейчас генерации, сервер
удалить не даст.

## Запуск и остановка

Из корня репо (в PowerShell — с `.\` впереди):

| Команда                                    | Что делает                         |
| ------------------------------------------ | ---------------------------------- |
| `studio start`                             | запустить ComfyUI и Mila Draw AI   |
| `studio stop`                              | остановить оба                     |
| `studio restart`                           | перезапустить оба                  |
| `studio start comfy` / `studio stop comfy` | только ComfyUI (и `restart comfy`) |
| `studio start web` / `studio stop web`     | только Mila Draw AI (и `restart web`) |
| `studio status`                            | что запущено и по каким адресам    |
| `studio logs web` / `studio logs comfy`    | смотреть лог, Ctrl+C — выйти       |

- Сервисы работают в фоне без окон и не гаснут, если закрыть терминал.
- `studio start` ждёт, пока сервисы ответят, и печатает адрес для телефона и Mac:
  `http://<IP MSI>:8000` — набирать целиком, с `http://` и `:8000`.
- Логи — `logs\comfy.log` и `logs\web.log` в корне репо (не в git).
- Логика — [msi/scripts/studio.ps1](../msi/scripts/studio.ps1).

### Первый запуск (один раз)

1. **Пароль** — скопировать `.env.example` в `.env`, вписать `STUDIO_PASSWORD`.
2. **Брандмауэр** — PowerShell от администратора:

   ```powershell
   New-NetFirewallRule -DisplayName "mila-draw-ai web interface" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
   ```

3. **Постоянный адрес** — резерв IP для MSI в роутере.

Нужно на машине: ComfyUI с моделями из каталога, `uv`, Claude Code CLI (`claude` в PATH, вход
выполнен). Без Claude всё работает, кроме описания картинок, ИИ-помощника и мозгового штурма.

## API

| Метод и путь                   | Что                                                         |
