# web-interface — рабочее место Милы

Локальный веб-интерфейс проекта. Через него Мила (и Павел) работают с генерацией без
терминала и без ComfyUI — с ноутбука, планшета или телефона в домашней сети. Порядок работ и
статусы — в [плане MSI](../.claude/develop/msi/plan.md), шаги 5–10. Этот файл — как он
устроен.

Статус (07.11.2026): **v1 работает** — задачи, генерация с предпромптами и LoRA, img2img,
очередь с прогрессом и таймером, галерея, библиотека, удаление фона, дневник и помощник промпта
от Claude. Проверено через API и в Chrome на ширине телефона и ноутбука. Ждёт пароля,
брандмауэра и первой сессии Милы.

## Сценарий

Мила садится с задачей, например «нарисовать персонажа X»:

1. **Заводит задачу** и прикладывает всё, что есть: концепт текстом, референсы, свои
   наброски. Набросок на бумаге можно сфотографировать телефоном прямо из интерфейса.
2. **Генерирует.** Пишет промпт — по-английски сама или по-русски через помощника (Claude
   переводит идею в промпт под модель). Выбирает модель: у каждой подсказка, для чего она.
   Включает LoRA и предпромпты галочками.
3. **Ждёт и видит, что происходит:** место в очереди, этап («загружаю модель», «шаг 12 из 30»),
   прогресс-бар и «осталось ≈ 25 с». Страница обновляется сама каждые 1–2 секунды.
4. **Работает с результатом:**
   - отмечает понравившиеся (★) и финальные;
   - убирает фон;
   - скачивает одну картинку или несколько сразу;
   - берёт картинку за основу для следующей или повторяет с правкой.
5. **Всё сохраняется** в `content/prototype/<задача>/`: что она принесла, что получила, с
   какими настройками. Claude после каждой порции работы обновляет **дневник задачи**: идеи
   Милы, что пробовали, что понравилось, следующий шаг.
6. **Персонаж готов** → по финальной картинке рисуется набор спрайтов в том же виде: позы ×
   эмоции, фон убран (шаг 8 плана).

Всё из `content/references/` (рисунки Милы, мудборд) видно в интерфейсе: посмотреть, скачать,
приложить к задаче, взять за основу.

## Экраны

Сначала под телефон, на широком экране колонки встают рядом. Интерфейс по-русски, кнопки
крупные.

- **Вход** — общий пароль и «кто я» (Мила, Павел…). Запоминается в браузере.
- **Полоса очереди** — сверху на всех экранах: что сейчас рисуется, прогресс, сколько
  осталось, сколько в очереди. Нажал — открылась очередь с отменой своих задач.
- **Задачи** — список: название, тип, превью последней картинки, когда менялась. Кнопка
  «Новая задача».
- **Задача** — вкладки:
  - **Генерация** — форма:
    - модель — карточки с подсказкой;
    - промпт с кнопкой «помочь с промптом»;
    - негатив — прячется, если у модели он не работает;
    - предпромпты — галочки по группам;
    - LoRA — добавить, убрать, сила ползунком;
    - размер: фон 16:9, спрайт 9:16, квадрат;
    - сколько вариантов: 1–4;
    - seed;
    - «за основу» — картинка и сила изменения;
    - «Дополнительно» (свёрнуто): шаги, CFG, сэмплер.
  - **Картинки** — сетка результатов. По нажатию — крупно, «как сделано» и кнопки: скачать,
    ★, финал, ещё такие же, повторить с правкой, за основу, убрать фон.
  - **Входящее** — референсы, наброски, заметки. Загрузка нескольких файлов сразу и с камеры.
  - **Дневник** — `notes.md` от Claude и кнопка «подвести итог».
- **Библиотека** — `content/references/`, `generated/`, `benchmarks/` по папкам: смотреть,
  скачать, приложить к задаче. Добавить файл в `references/` можно, удалить — нет.

## Устройство

| Что          | Как                                                                                       |
| ------------ | ----------------------------------------------------------------------------------------- |
| Где живёт    | MSI, рядом с ComfyUI и главной копией `content/`                                          |
| Сервер       | Python 3.13, FastAPI + uvicorn, окружение через `uv` (`pyproject.toml` в этой папке)       |
| Страница     | HTML + CSS + JS без сборки и без CDN: работает без интернета, правится в любом редакторе   |
| ComfyUI      | только `127.0.0.1:8188`, с ним говорит один сервер интерфейса                              |
| Сеть         | интерфейс на порту **8000**, правило брандмауэра — только частная сеть. В интернет не выставлять |
| Вход         | общий пароль из `.env` (не в git) + «кто я» для дневника                                  |
| Картинки     | читает и пишет `content/` по правилам [content.md](../.claude/develop/mac/content.md)      |
| Каталог      | модели и LoRA — [msi/catalog/](../msi/catalog/), предпромпты — [prompts/blocks.json](../prompts/blocks.json) |
| Claude       | Claude Code без интерфейса (`claude -p`), с ограниченными инструментами — ниже            |

Почему так:

- **Python, а не Node.** На MSI уже есть `uv`, а скрипты проекта на Python. Node ради одного
  интерфейса не ставим.
- **Без сборки фронтенда.** Интерфейс простой, и его будем часто менять по отзывам Милы;
  `npm run build` в этом цикле лишний.
- **ComfyUI не торчит в сеть.** У него нет авторизации. Наружу смотрит один порт интерфейса с
  паролем. Для Krita (шаг 11) ComfyUI откроем в сеть отдельно.
- **Пароль внутри домашней сети.** Интерфейс запускает Claude и пишет файлы — пусть это будет
  не любой гость в Wi-Fi.

```

│   ├── config.py        пути и настройки
│   ├── catalog.py       модели, LoRA, предпромпты
│   ├── graphs.py        сборка графов ComfyUI (общий модуль с comfy_generate.py)
│   ├── comfy.py         клиент ComfyUI: очередь, websocket, картинки
│   ├── jobs.py          очередь интерфейса, прогресс, оценка времени

```

### Запуск

```bat
web-interface\start.bat
```

Батник поднимает ComfyUI (если он ещё не отвечает на `127.0.0.1:8188`), затем сервер, и
печатает адрес для других устройств: `http://<IP MSI>:8000`. Позже — автозапуск через
Планировщик заданий.

### Первый запуск (один раз)

1. **Пароль.** Скопировать `.env.example` в `.env` и вписать `STUDIO_PASSWORD`. Без пароля
   войти может любой в домашней сети — сервер предупредит об этом в консоли.
2. **Брандмауэр** — PowerShell от администратора:

   ```powershell
   New-NetFirewallRule -DisplayName "mila-draw-ai web interface" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
   ```

   Если при первом запуске Windows сама спросит про доступ для Python — разрешить только
   для частных сетей.
3. **Постоянный адрес** — резерв IP для MSI в настройках роутера, чтобы ссылка на
   телефоне и Mac не менялась.
4. Запустить `start.bat`, открыть адрес из консоли на другом устройстве.

Окружение ставится само при первом `uv run`. Зависимости — в `pyproject.toml`.

### Что нужно на машине

- ComfyUI с моделями из [msi/catalog/models.json](../msi/catalog/models.json) и BiRefNet в
  `models/background_removal/birefnet.safetensors` ([Comfy-Org/BiRefNet](https://huggingface.co/Comfy-Org/BiRefNet), MIT).
- `uv` и Claude Code CLI (`claude` в PATH, вход выполнен). Без Claude интерфейс работает, но
  дневника и помощника промпта нет.

### Сколько стоит Claude

Замеры 07.11.2026 на Sonnet: дневник — ≈ 17 с и ≈ $0,08 за обновление, помощник промпта —
≈ 11 с и ≈ $0,05. Дневник обновляется не чаще, чем раз в `STUDIO_JOURNAL_DELAY` секунд тишины
в задаче (по умолчанию 90), и только при пустой очереди генерации.

## Задачи: `content/prototype/`

Одна задача — одна папка `content/prototype/<ГГГГ-ММ-ДД>-<slug>/`, где дата — день создания:

```
2026-11-07-mark-concept/
├── task.json        название, тип, кто создал, статус, финальные картинки
├── inputs/          что принесли: референсы, наброски (+ .json: кто, когда, заметка)
├── outputs/         что получили: <модель>_<seed>.png + .json (граф и параметры формы)
├── log.jsonl        всё, что происходило, по строке на событие
└── notes.md         дневник задачи — ведёт Claude
```

События в `log.jsonl` (у каждого есть `time`, `who` и `kind`):

| `kind`        | Что                                                            |
| ------------- | -------------------------------------------------------------- |
| `created`     | задача заведена                                                |
| `upload`      | файл во `inputs/` (из библиотеки — с пометкой, откуда)         |
| `note`        | заметка или идея текстом                                       |
| `generate`    | отправлена генерация: все параметры формы                      |
| `image`       | готова картинка: файл, секунды, seed                           |
| `error`       | генерация упала: текст ошибки                                  |
| `star`, `final` | отметки (и их снятие)                                        |
| `nobg`        | убран фон                                                      |
| `prompt_help` | помощник промпта: идея по-русски → промпт                      |
| `claude`      | запуск Claude: что обновил, сколько шёл                        |

## API (черновик)

| Метод и путь                        | Что                                                    |
| ----------------------------------- | ------------------------------------------------------ |
| `POST /api/login`                   | пароль + «кто я» → cookie                              |
| `GET /api/catalog`                  | модели, LoRA, предпромпты, размеры                     |
| `GET /api/tasks`, `POST /api/tasks` | список задач, новая задача                             |
| `GET /api/tasks/{id}`               | задача: входящее, картинки, дневник                    |
| `POST /api/tasks/{id}/uploads`      | загрузка файлов (multipart)                            |
| `POST /api/tasks/{id}/notes`        | заметка                                                |
| `POST /api/tasks/{id}/marks`        | ★ / финал                                              |
| `POST /api/jobs`                    | генерация: задача, модель, промпт, блоки, LoRA, размер, сколько, seed, основа |
| `GET /api/jobs`                     | очередь: этап, прогресс, сколько осталось              |
| `DELETE /api/jobs/{id}`             | отмена                                                 |
| `POST /api/images/nobg`             | убрать фон у картинки                                  |
| `GET /api/library?path=…`           | папка `content/`                                       |
| `GET /files/{путь}`, `GET /thumbs/{путь}` | файл из `content/` и его превью                  |
| `POST /api/tasks/{id}/journal`      | «подвести итог» — запустить Claude                     |
| `POST /api/prompt-help`             | помощник промпта                                       |

## Прогресс и оценка времени

- Сервер держит websocket ComfyUI (`/ws?clientId=…`): номер шага и сколько всего шагов, какой
  узел выполняется, готово или ошибка. Из этого получается этап: в очереди → загружаю модель
  → шаг k из N → сохраняю → готово.
- Браузер опрашивает `GET /api/jobs` раз в 1–2 с. На телефоне это надёжнее постоянного
  соединения, а точности хватает.
- **Сколько осталось:**
  - до старта — медиана секунд на картинку для этой модели и размера по истории (`log.jsonl`
    прогонов и задач), плюс загрузка модели, если в памяти другая;
  - во время сэмплинга — оставшиеся шаги × реальная скорость шага плюс декодирование;
  - для очереди — сумма по задачам перед твоей.

## Claude

Сервер запускает `claude -p` (Claude Code без интерфейса, подписка Павла) с инструкцией из
`claude/`:

- **Ограничения:**
  - рабочая папка — репо;
  - запись — только в папку задачи и в `content/prototype/README.md`;
  - чтение — ещё карточки `.claude/vibe-description/` и `prompts/`;
  - без Bash и без сети.
- **Когда:** только при пустой очереди генерации (16 ГБ RAM: Claude не должен мешать FLUX).
  Сбой Claude не останавливает генерацию.
- **Дневник** (`notes.md`): после паузы ≈ 1–2 мин после новых событий или по кнопке. Claude
  читает новые записи `log.jsonl`, смотрит новые картинки и обновляет:
  - концепт и идеи Милы — её словами;
  - что важно в референсах;
  - что пробовали;
  - что понравилось и почему;
  - открытые вопросы и следующий шаг.
- **Сводка задач** — `content/prototype/README.md`: все задачи, статус, ссылка на дневник.
- **Помощник промпта:** идея по-русски → промпт под семейство модели по правилам
  [prompts/bake-off.md](../prompts/bake-off.md), с учётом карточек и включённых блоков.
- **Карточки проекта** (`.claude/vibe-description/`) Claude не правит: при «финале» он
  готовит `card-proposal.md` в папке задачи, Павел переносит и коммитит.
