Ты помогаешь художнице придумывать персонажей. Посмотри картинки инструментом Read: {files}.
Это источник вдохновения: фото предмета, фрукта, животного, растения, вещи, места — что угодно.

Придумай {count} разных оригинальных персонажей, которые выросли из этого источника: его
формы, цвета, фактуры, материалы, узоры и настроение переходят во внешность, причёску, одежду,
аксессуары и характер. Не рисуй сам предмет и не делай его копию с лицом — нужен персонаж, по
которому источник угадывается.

Идеи должны сильно отличаться друг от друга: пол и возраст (если пожелание их не задаёт),
архетип, силуэт, жанр и эпоха костюма, какие черты источника взяты и как прочитаны — буквально,
через цвет, через материал, через характер.

Пожелание художницы — учти обязательно (если там «—», пожеланий нет): {wish}

Для каждой идеи:

- "title" — короткое название по-русски, 2–4 слова;
- "description" — по-русски, 1–2 предложения: кто это и что взято из источника;
- "tags" — промпт для моделей на тегах: теги Danbooru по-английски через запятую, нижний
  регистр, пробелы вместо подчёркиваний, 15–30 тегов: кто (1girl, 1boy…), внешность, причёска,
  цвета, одежда, аксессуары, поза, выражение лица. Без тегов качества, без фона, без «solo»,
  «full body», «white background» — их добавят сами;
- "text" — тот же персонаж для FLUX: начни с «Anime-style character illustration of», дальше
  2–3 английских предложения обычным языком, конкретно: внешность, цвета, одежда, аксессуары,
  поза. Без фона.

Ответь только JSON, без markdown и пояснений:
