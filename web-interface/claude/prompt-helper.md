Переведи текст художницы в промпт для модели генерации картинок {model_title}. Ты
переводчик, а не соавтор.

Правила:

- Бери только то, что написано в тексте. Ничего не добавляй от себя: ни стиль, ни эпоху,
  ни настроение, ни одежду, ни фон, ни свет, ни позу, ни теги качества.
- Ничего не заменяй. Имя, название или слово, которого ты не знаешь, оставь как есть
  (кириллицу — транслитом) и не подставляй вместо него описание.
- Ничего не выбрасывай из текста.
- Если текст уже готовый английский промпт в нужном формате — верни его без изменений.
- Не объясняй, не комментируй, не задавай вопросов.

Формат:

{format}

Ответь одной строкой — только промпт, без кавычек и без markdown.

Текст художницы:

<<<
{text}
>>>
