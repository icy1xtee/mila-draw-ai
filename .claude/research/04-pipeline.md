# 04. Как собрать конвейер под новеллу и с чего начать

## Что нужно игре

Из `on-the-other-side-webapp` на 28.10.2026:

- **Фоны.** Сцена тянется на весь экран (`object-fit: cover`). Макет 1280×720, проверяется на
  1920×1080 и 2560×1080 (ультраширокий обрезает 16:9 сверху и снизу).
  → **мастер фона 2560×1440** (16:9), экспорт WebP.
- **Спрайты.** Персонаж в полный рост, на прозрачном фоне.
  → **мастер спрайта ≈ 2000 px по высоте с альфой**, один ракурс и одна высота камеры на всех
  персонажей.
- **Портреты.** Кроп из спрайта.
- **Стиль.** Semi-realism anime. Референсы стиля задаёт художник (открытый вопрос 3).

## Конвейер

```
           ┌──────────── «библия» проекта (репо mila-draw-ai) ────────────┐
           │ персонажи, локации, палитры, шаблоны промптов, JSON-воркфлоу │
           └──────────────┬───────────────────────────────┬───────────────┘
                          │ Claude Code + comfyui-mcp     │
                          ▼                               ▼
   ФОНЫ: Anima (или Illustrious) + style LoRA     СПРАЙТЫ: VNCCS
   1536×864 → hires-fix → апскейл 2560×1440        Illustrious + LoRA стиля + LoRA персонажа
                          │                        позы → костюмы → эмоции → вырезание фона
                          ▼                               │
   ПРАВКИ: FLUX 3 Image Klein (edit + bbox + референсы)   │
           Krita AI: выделить → перерисовать той же моделью и LoRA
           FaceDetailer — лица и руки                     │
                          └───────────────┬───────────────┘
                                          ▼
                     ручная доводка художником → WebP в webapp/src/assets
```

### Как закрывается каждое требование

1. **Хорошие фоны.**
   - Anima: сильные свет и атмосфера. Для сравнения — Illustrious.
   - Генерировать в ≈ 1536×864, затем hires-fix (второй проход с denoise 0.3–0.45) и тайловый
     апскейл до 2560×1440 той же моделью.
   - Для ракурсов и перспективы — ControlNet (lineart / depth) по наброску или 3D-болванке.
2. **Правки деталей по требованию.**
   - Глобальные правки («сделай вечер», «убери коробку», «добавь дождь за окном») — FLUX 3 Image
     Klein в режиме edit, с bounding box на область.
   - Локальные правки — Krita AI Diffusion: выделение → перерисовка той же моделью и LoRA, что
     рисовали. Так стиль не уезжает.
   - Запасные редакторы: Qwen-Image-2.1 (некоммерческая), FLUX.2 klein 4B (Apache 2.0).
3. **Понимание контекста.**
   - Референсы в edit-моделях: «вот персонаж, вот локация — поставь его у окна».
   - Библия проекта и шаблоны промптов в репо, которые Claude подставляет сам.
   - comfyui-mcp: генерация по запросу из Claude Code.
4. **Спрайты.**
   - VNCCS: создать персонажа по описанию (или клонировать с утверждённого концепт-арта) → позы
     → костюмы → эмоции → вырезание фона.
   - Для устойчивости — LoRA персонажа, обученная на лучших результатах (VNCCS сам собирает
     датасет).
5. **Копирование стиля художника.**
   - Style LoRA на 50–150 работах художника, с подписями (теги + короткое описание).
   - Учить параллельно на Illustrious и на Anima Base и сравнить на одних промптах.
   - На Katana обе влезают в 8 ГБ.
6. **Немного артефактов.**
   - DiT-модели 2026 года (Anima, FLUX 3, Qwen) ошибаются в руках и анатомии реже SDXL.
   - FaceDetailer / ADetailer — автоматически перерисовать лица и руки.
   - Отбор: из 4–8 вариантов взять лучший, остальное поправить inpaint.
   - Финальный проход художника обязателен для того, что идёт в игру.
7. **Нормальное разрешение.**
   - Нативно 1–2 МП (Qwen / FLUX 3 умеют 2K–4K), дальше апскейл.
   - 2560×1440 для фона и ≈ 2000 px по высоте для спрайта достижимы на обеих машинах.

Отдельно — **датасет для style LoRA.** Обучать на работах конкретного художника стоит только
с его согласия: свой художник, заказанные арты или собственные рисунки. Это и этично, и
снимает юридические вопросы при релизе.

## План первых шагов

Каждый шаг — одна проверяемая вещь, как в webapp.

0. **Вводные.** Узнать суффикс Katana 17 B12V (`nvidia-smi`, наклейка) и RAM. Ответить на
   открытые вопросы ниже.
1. **Установка** — по [msi/README.md](../../msi/README.md) и [mac/README.md](../../mac/README.md).
   - Katana: ComfyUI Desktop + ComfyUI-Manager.
   - Mac: Draw Things.
   - Скачать: WAI-Illustrious v17 (или NoobAI-XL), Anima Aesthetic + Base + Turbo,
     FLUX 3 Image Klein (INT8 / FP8).
   - Записать замеры скорости: `mac/benchmarks.md`, `msi/benchmarks.md`.
2. **Сравнение моделей.** Одинаковый набор:
   - 5 разных фонов (интерьер и экстерьер, день и ночь);
   - 3 спрайта персонажей по текстовому описанию;
   - 3 правки по инструкции.
   Сравнить по стилю, артефактам и скорости, выбрать основную модель для фонов и для спрайтов.
3. **Krita AI Diffusion** на Katana: проверить цикл «выделил → перерисовал» на одном фоне.
4. **Датасет стиля** (50–150 работ) → первая style LoRA (OneTrainer / sd-scripts на Katana).
   Пробный прогон 200 шагов, затем полный.
5. **VNCCS:** создать персонажа (Creator) или клонировать с концепт-арта Милы, 3 позы × 6 эмоций,
   прозрачный фон → собрать датасет → LoRA персонажа.
6. **Фоны в продакшн-разрешении:** hires-fix + апскейл до 2560×1440, экспорт WebP, проверить в
   игре на 1920×1080 и 2560×1080.
7. **Claude Code ↔ ComfyUI** через comfyui-mcp. Библия проекта (`characters/`, `locations/`,
   `prompts/`) в репо.
