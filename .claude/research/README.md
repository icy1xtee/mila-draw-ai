# Ресерч: локальная генерация артов для новеллы

Дата: **28.10.2026**. Задача — поднять локально нейросеть, которая рисует фоны и спрайты в стиле
semi-realism anime для «On the Other Side»:

- исправляет детали по просьбе;
- держит контекст проекта;
- копирует стиль художника, на котором дообучена;
- даёт мало артефактов;
- работает в нормальном разрешении.

## Коротко

1. **Одной «универсальной» модели нет — нужна связка из 2–3 моделей** в ComfyUI. Это не LLM, а
   диффузионные модели; LLM у них внутри как текстовый энкодер. «Понимание контекста» дают
   edit-модели с референсами, LoRA и Claude Code поверх ComfyUI через MCP.
2. **Рекомендуемый стек:**
   - **Anima** (2B, аниме-нативная, 2026) — фоны;
   - **Illustrious XL** и наследники (SDXL, крупнейшая аниме-экосистема) — спрайты и style
     LoRA;
   - **FLUX 3 Image Klein** (5.6B, вышла 15.10.2026; редактирование, bounding boxes, до 10
     референсов) — правки по инструкции;
   - **Qwen-Image-2.1** (сильнейшая открытая, прозрачный фон) — мощная, но некоммерческая
     лицензия: только для прототипа или после покупки лицензии.
3. **Инструменты:**
   - **ComfyUI** (144k ★) — движок;
   - **Krita AI Diffusion** (10.8k ★) — правки «как художник»;
   - **ComfyUI_VNCCS** (1.7k ★) — готовый конвейер спрайтов для визуальных новелл: позы,
     костюмы, эмоции, вырезание фона;
   - **Draw Things** — на Mac;
   - **OneTrainer / sd-scripts** — обучение LoRA;
   - **comfyui-mcp** — связка с Claude Code.
4. **Железо:**
   - **Katana 17 B12V** (i7-12650H, 16 ГБ DDR5; GPU по суффиксу: RTX 4050 6 ГБ, 4060 8 ГБ или
     4070 8 ГБ) — основная рабочая станция: генерация, пачки, LoRA на SDXL и Anima. Если там
     RTX 4050, опора смещается на Anima, а правки уходят на Mac;
   - **MacBook Air M4 24 ГБ** — памяти хватает, но GPU слабый и без вентилятора: черновики и
     точечные правки, минуты на картинку;
   - Самый полезный апгрейд — RAM в Katana до 32 ГБ. LoRA для больших моделей проще учить в
     облаке за пару долларов.
5. **Первый шаг** — сравнить Anima, Illustrious и FLUX 3 Klein на одном наборе фонов и спрайтов
   персонажей и замерить скорость на обеих машинах.
