# 01. Железо: что на чём реально запускать

Срез на 28.10.2026. Цифры скорости — ориентиры из чужих замеров на соседнем железе, пересчитанные
на наше; помечены «≈». Свои замеры сделать на первом же шаге (см. [04-pipeline.md](04-pipeline.md)).

## MacBook Air 13" M4 (2025), 24 ГБ

| Параметр           | Значение                                                                  |
| ------------------ | ------------------------------------------------------------------------- |
| CPU / GPU          | 10 ядер CPU, **10 ядер GPU** (конфигурация с 24 ГБ идёт с 10-ядерным GPU) |
| Память             | 24 ГБ unified, пропускная способность **120 ГБ/с**                        |
| Охлаждение         | **пассивное** (нет вентилятора) → троттлинг на длинных пачках             |
| Бэкенд             | Metal / MPS / MLX, **нет CUDA**                                           |
| Доступно GPU       | macOS по умолчанию отдаёт GPU ≈ 2/3–3/4 памяти (≈ 16–18 ГБ из 24)         |

Лимит памяти для GPU можно поднять: `sudo sysctl iogpu.wired_limit_mb=20480` (сбрасывается
после перезагрузки). Пользоваться осторожно, macOS нужно оставить хотя бы 4 ГБ.

**Что это значит на практике**

- Объём памяти хороший: в 24 ГБ влезают почти все актуальные модели в 4–8-битной квантизации,
  включая Qwen-Image-2.1 (4-bit) и FLUX.2 klein 9B (int8)
  ([modelfit.io](https://modelfit.io/guides/local-image-generation-mac/)). Тяжёлые FLUX.2 [dev]
  (32B) и HunyuanImage 3.0 (80B) не помещаются.
- Узкое место — вычисления, а не память. 10-ядерный GPU M4 примерно в 2–3 раза слабее M1 Max
  (32 ядра, 400 ГБ/с) и примерно вдвое слабее M4 Pro.
- Ориентиры:
  - Anima Base (DiT 2B), 832×1216, ComfyUI: на M1 Max ≈ 275 с на картинку, с Turbo-LoRA (8 шагов)
    ≈ 47 с ([lilting.ch](https://lilting.ch/en/articles/anima-base-v1-preview3-compare-lora-compat)).
    На M4 Air ≈ **2 мин с Turbo**, ≈ 8–10 мин без него.
  - FLUX.1 dev Q6, 1024², 20 шагов в Draw Things: на M4 Pro ≈ 50 с
    ([heyuan110](https://www.heyuan110.com/posts/ai/2026-02-15-mac-mini-local-image-generation/)),
    на M4 Air ≈ 2–2.5 мин.
  - Qwen-Image 2512 + Lightning (4 шага), 768×1152 в Draw Things: на M4 Pro 70 с
    ([Draw Things в X](https://x.com/drawthingsapp/status/2006697869982707735)), на M4 Air ≈ 2.5–3 мин.
- **Draw Things** на Mac заметно быстрее ComfyUI, потому что у него свой движок на Metal, а не
  PyTorch MPS (один из обзоров пишет про ≈ 40 %,
  [heyuan110](https://www.heyuan110.com/posts/ai/2026-02-15-draw-things-ultimate-guide/)). С апреля
  2026 он умеет Neural Engine на M4 для 8-битных моделей.
- Обучение LoRA на Mac: kohya / ai-toolkit / musubi рассчитаны на CUDA. Встроенный тренер Draw
  Things умеет SDXL, FLUX.2 klein, Z-Image, Qwen Image и Anima. Работает, но медленно, а
  пассивное охлаждение растягивает многочасовой прогон ещё сильнее.

**Роль Mac в проекте:** черновики, превью идей, точечные правки (inpaint небольших областей),
работа в Krita / Draw Things «как художник». Пачки и обучение на нём не делаем.

## MSI Katana 17 B12V (2023)

> **07.11.2026: суффикс — B12VFK, RTX 4060 Laptop 8 ГБ.** RAM 16 ГБ = 2 × 8 ГБ (оба гнезда
> заняты), SSD Micron 2400 **512 ГБ** — не 1 ТБ, после чистки свободно 238 ГБ, на рабочий набор хватает. Полная конфигурация — в
> [msi/README.md](../../msi/README.md). Ниже — исходный разбор по линейке: актуален раздел
> «для 8 ГБ», варианты B12VEK и B12VGK оставлены для истории.

Ниже — данные по линейке (MS-17L5)
([Notebookcheck](https://www.notebookcheck.net/MSI-Katana-17-B12VFK.733409.0.html),
[MSI](https://www.msi.com/Laptop/Katana-17-B12VX/Specification)).

| Параметр   | Значение                                                                          |
| ---------- | --------------------------------------------------------------------------------- |
| CPU        | Intel Core i7-12650H (10 ядер / 16 потоков, Alder Lake), в части SKU — i5-12450H   |
| GPU        | зависит от суффикса, см. таблицу ниже. Лимит до 105 Вт, MUX-переключатель          |
| RAM        | **16 ГБ DDR5-4800**, 2 слота SO-DIMM, максимум **64 ГБ**                           |
| Накопитель | M.2 PCIe 4.0 (обычно 1 ТБ)                                                        |
| Экран      | 17.3" FHD IPS 144 Гц, ≈ 51 % sRGB — **для оценки цвета не годится**               |
| Бэкенд     | **CUDA** — работает весь софт без исключений                                      |

| Суффикс    | GPU                   | VRAM      | Что это меняет                                         |
| ---------- | --------------------- | --------- | ------------------------------------------------------ |
| **B12VEK** | RTX 4050 Laptop       | **6 ГБ**  | тесно: SDXL на пределе, FLUX 3 Klein только с выгрузкой в RAM |
| **B12VFK** | RTX 4060 Laptop       | **8 ГБ**  | базовый сценарий ниже                                  |
| **B12VGK** | RTX 4070 Laptop       | **8 ГБ**  | как 4060 по памяти, ≈ на 15–25 % быстрее                |

Суффикс видно на наклейке снизу (`Katana 17 B12VFK-xxx`) или в `nvidia-smi` (модель GPU и объём
памяти).

Нагрев: в обзоре RTX 4060 в этом корпусе под полной нагрузкой брала ≈ 85 Вт из 105 Вт лимита
(режим Extreme Performance). Длинные пачки она выдержит, но скорость будет чуть ниже, чем у
той же карты в толстом корпусе.

**Что это значит на практике** (для 8 ГБ, B12VFK / B12VGK; отличия для B12VEK — ниже)

- SDXL-семейство (Illustrious / NoobAI): комфортно. На RTX 4060 Laptop WAI-Illustrious в 1024² с
  LoRA пиково занимает ≈ 5.6 ГБ VRAM
  ([lilting.ch](https://lilting.ch/en/articles/comfyui-local-rtx4060-wai-illustrious)). Скорость
  ≈ 10–20 с на картинку.
- Anima (2B): комфортно, есть GGUF-кванты по 1–2 ГБ.
- FLUX 3 Image Klein (5.6B): сборка INT8 официально рассчитана на RTX с 8 ГБ. BFL меряет на
  RTX 4070: генерация 1024² за 8.9 с, правка за 18.9 с
  ([VentureBeat](https://venturebeat.com/technology/black-forest-labs-opens-flux-3-image-klein-weights-with-free-commercial-use-limited-to-smaller-businesses)).
  На 4060 Laptop ≈ 15–20 с и ≈ 30–40 с.
- Qwen-Image-2.1 (7B + энкодер 8B): GGUF Q4 хочет ≈ 11 ГБ VRAM, FP8 с выгрузкой в RAM
  запускается от 6 ГБ, но медленнее ([Unsloth](https://unsloth.ai/docs/models/qwen-image-2.1)).
  При 16 ГБ RAM это тесно.
- Обучение LoRA:
  - SDXL / Illustrious на 8 ГБ — реально (fp16, gradient checkpointing, кэш латентов, batch 1,
    AdamW8bit). ≈ 1–2 ч на 1500–2000 шагов (оценка; на 4060 Ti 16 ГБ — ≈ 30 мин,
    [vrlatech](https://vrlatech.com/stable-diffusion-lora-training-hardware-requirements/)).
  - Anima (2B) — реально.
  - FLUX 3 Klein / Qwen / Krea 2 — на 8 ГБ мучительно. Проще арендовать облачный GPU на пару
    часов (RunPod / Vast.ai, RTX 4090/5090 ≈ $0.3–0.9/ч) или обучать в Draw Things на Mac.

**Если это B12VEK (RTX 4050, 6 ГБ):**

- **Anima (2B)** — основная модель, влезает с запасом.
- **SDXL / Illustrious** — работает, но на пределе (пиковые 5.6 ГБ из замера выше). Нужны
  fp8-веса или `--lowvram`, tiled VAE и генерация в 1024 с апскейлом потом.
- **FLUX 3 Klein** — только с выгрузкой в RAM, заметно медленнее. Правки удобнее делать на Mac
  в Draw Things.
- **Обучение LoRA:** Anima реально; SDXL — на грани (fp8-база, batch 1). Надёжнее в облаке.

**Самый дешёвый и самый полезный апгрейд — RAM до 32 ГБ** (2×16 ГБ DDR5-4800 SO-DIMM,
максимум 64 ГБ). Обычно 16 ГБ стоят как 2×8, то есть оба слота заняты и обе планки придётся
заменить; проверить: Диспетчер задач → Производительность → Память → «Использовано гнезд». С
32 ГБ большие модели (Qwen-Image-2.1, FLUX.2 klein 9B, FLUX 3 Klein на 6 ГБ) выгружаются с GPU
в RAM без свопа на диск. Для B12VEK это почти обязательно.

**Роль Katana в проекте:** основная рабочая станция. ComfyUI, пачки фонов и спрайтов, обучение
LoRA на SDXL / Anima. Работать от сети, в MSI Center режим «Extreme Performance». Цвет
проверять не на её экране (≈ 51 % sRGB), а на Mac.

### Что прислать для точной картины

- Полное имя модели с наклейки (`Katana 17 B12VxK-xxx`).
- Вывод `nvidia-smi` в PowerShell: модель GPU и объём VRAM.
- Диспетчер задач → Производительность → Память: объём RAM и «Использовано гнезд: x из 2».
- Объём свободного места на SSD: модели занимают 5–25 ГБ каждая, на набор из шорт-листа нужно
  ≈ 80–120 ГБ.
