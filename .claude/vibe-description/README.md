# vibe-description — мир, места и персонажи

Из чего собираются промпты: каким должен быть мир игры, её места и персонажи. Всё здесь —
**предварительный демо-концепт** (03.11.2026), он будет часто меняться.

```
vibe-description/
├── README.md        этот файл: устройство и шаблон карточки
├── world.md         мир целиком: суть, правила, свет и цвет, слои города, улица, жизнь
├── locations.md     карточки мест
├── characters.md    карточки персонажей
└── sources/         исходники, как их прислал Павел, без правок; дата в имени файла
```

## Как это работает

- **`sources/` — первоисточник.** Его не правим. Новое описание или уточнение — новый файл
  `<ГГГГ-ММ-ДД>-<тема>.md`.
- **Карточки — всё, сведённое к одному формату.** В каждой собрано из всех источников, что
  известно о мире, месте или персонаже. Где источники расходятся, карточка выбирает рабочий
  вариант и пишет о расхождении в «Открыто».
- **Промпты собираются из карточек.** У карточки есть `id`, и в [prompts/](../../prompts/) он
  же — `id` промпта, так что найти связанный промпт просто. Карточка изменилась — поправить
  промпты с этим `id`.
- Карточки пишем по-русски. Промпт-ядро — по-английски: модели понимают английский.

## Шаблон карточки

```markdown
## <Название> — `<id>`

Статус: демо-концепт | утверждено

- **Суть** — одна-две фразы: что это и зачем в истории.
- **Где в городе** — (места) слой города из world.md, ракурс.
- **Как выглядит** — обязательные детали кадра; для персонажа — возраст, телосложение,
  внешность, одежда.
- **Свет и цвет** — (места) источники света и палитра из world.md.
- **Настроение** — для места; для персонажа — **поза и характер**: как их показать.
- **Промпт-ядро (EN)** — абзац на английском, от него отталкиваются промпты всех моделей.
- **Открыто** — расхождения источников и решения, которые ещё не приняты.
- **Источники** — ссылки на `sources/`.
```

## Правила для промпт-ядра

Из опыта первых прогонов (подробности — [prompts/bake-off.md](../../prompts/bake-off.md)):

- **Никаких имён своих персонажей и чисел.** Модель дописывает их на картинку текстом. Рост,
  возраст, внешность — словами.
- **Никаких реальных стран.** Город вымышленный. Тег `russia` и «post-Soviet» дали не то, что
  нужно. Для плотности и вывесок можно сравнивать с Гонконгом, для кирпича и пожарных
  лестниц — со старым Нью-Йорком.
- Обязательные детали — в начале абзаца, настроение и зерно — в конце.
