# План: MSI (Katana 17 B12VFK, RTX 4060 8 ГБ)

Составлен 07.11.2026. Роль MSI и выбор моделей обоснованы в [research/](../../research/README.md);
конфигурация, установка и настройки — в [msi/README.md](../../../msi/README.md). План Mac —
[develop/mac/plan.md](../mac/plan.md).

## Исходное состояние (проверено 07.11.2026)

- Katana 17 B12VFK: i7-12650H, **RTX 4060 Laptop 8 ГБ**, 16 ГБ DDR5 (2 × 8, оба слота заняты).
  Windows 11 Pro 26300.
- **SSD 512 ГБ, свободно 131 ГБ** (после удаления Infinity Nikki — 238 ГБ, см. журнал) —
  главное ограничение. Стартовый набор моделей из ресерча
  (80–120 ГБ) и окружения Python (≈ 20 ГБ) с запасом не влезают. **Новый SSD не покупаем**
  (решение Павла, 07.11.2026): место освобождаем по мере необходимости.
- Есть: драйвер NVIDIA 610.78 (CUDA 13.3), Git 2.56, MSI Center 2.0.71, схема питания «Высокая
  производительность».
- Нет: Python (`python` — заглушка Microsoft Store), uv, ComfyUI, тренеры, `cwebp`, Krita.
- Длинные пути в Windows выключены (`LongPathsEnabled = 0`) — включены в шаге 1.
- Wi-Fi в профиле «Общедоступная» — переведён в «Частную» в шаге 1. Есть VPN-интерфейс `tun0`,
  он может мешать доступу с Mac.
- `content/` на MSI нет. Рисунки Милы (105 PNG) и прогоны Mac лежат только на Mac.

## Главная мысль

MSI нужен для трёх вещей, которых Mac не может или делает слишком медленно:

1. **Скорость.** Картинка ≈ 1 Мп здесь — секунды, а не минуты. Это меняет работу: можно
   перебирать варианты, а не ждать ночь.
2. **Обучение LoRA** стиля Милы и персонажей — на Illustrious и Anima, локально.
3. **Сервер ComfyUI** для Krita на Mac и для Claude Code.

Ставим по слоям: Windows → ComfyUI → модели → скрипт генерации → сервер для Mac → обучение.
Каждый шаг заканчивается проверкой.

**Сравнение моделей делаем на MSI** (решение Павла, 07.11.2026) — шаг 4, сразу после настройки
ComfyUI. Здесь оно займёт ≈ 30–60 мин вместо ≈ 6,5 ч на Mac. Весь прогон — в одном движке
(ComfyUI); превью Mac на Anima Turbo с ним по seed не сравниваем.

**Диск.** Правило: держать ≥ 30 ГБ свободными (файл подкачки, кэш, временные файлы). Перед
каждой новой моделью — проверить место; не хватает — удалить то, что не используется
(проигравшие в сравнении модели, кэш pip / uv, старые прогоны после переноса через
веб-интерфейс).

**Веб-интерфейс** ([web-interface/](../../../web-interface/README.md)) — способ передавать
`content/` между машинами, а позже — пульт управления генерацией для Павла и его девушки.
Скорее всего живёт на MSI, рядом с ComfyUI. Шаг 10.

## Шаги

Статусы: ☐ — не начат, ◐ — в работе, ☑ — готов.

### ☑ 0. Вводные: железо

- ☑ Суффикс B12VFK, RTX 4060 8 ГБ, RAM 2 × 8 ГБ, SSD 512 ГБ. Записано в `msi/README.md` и в
  ресерч.

### ◐ 1. Подготовка Windows

- ☑ Место на диске. Обмер 07.11: Program Files 273 ГБ, из них Genshin Impact 152 ГБ и
  Infinity Nikki 116 ГБ; Windows 42 ГБ, профиль 14 ГБ. Павел удалил Infinity Nikki →
  **свободно 238 ГБ**. Этого хватает на урезанный набор моделей (≈ 40 ГБ), окружения (≈ 20 ГБ)
  и рабочий запас.
- ☑ Длинные пути: `LongPathsEnabled = 1` (PowerShell от администратора, затем перезагрузка).
- ☑ Сеть: домашний Wi-Fi (`TP-Link_7774 2`) → профиль «Частная». VPN на время работы с Mac выключать или
  проверить, что локальная сеть через него видна.
- ☐ MSI Center: режим **Extreme Performance** от сети; режим GPU — MSHybrid (не «только
  дискретная»), чтобы рабочий стол не занимал видеопамять.
- ☑ `uv` 0.13.7 (`winget install astral-sh.uv --scope user`, 07.11) — Python для наших скриптов и тренеров. Глобальный
  Python не ставим: у ComfyUI portable свой встроенный, у тренеров — свои окружения.
- ☐ (по желанию) Отключить сон при закрытой крышке от сети — для ночных прогонов и обучения.
- **Проверка:** `uv --version`, `nvidia-smi`, длинные пути включены, сеть «Частная».

### ☐ 2. ComfyUI

- ☐ **ComfyUI portable** (сборка для NVIDIA) в `C:\AI\ComfyUI\`, а не ComfyUI Desktop.
  Почему portable:
  - одна папка: модели, ноды, выход — всё в ней, видно, сколько занимает, легко чистить;
  - запуск из `.bat` с явными флагами (`--listen`, порт, путь вывода) — так же из скрипта и
    для Krita;
  - встроенный Python — не конфликтует с окружениями тренеров.
- ☐ Свой батник запуска `msi/scripts/comfy_start.bat` — в репо, чтобы флаги были записаны.
- ☐ ComfyUI-Manager — для установки custom nodes.
- **Проверка:** ComfyUI открывается на `http://127.0.0.1:8188`, `nvidia-smi` показывает
  процесс, стандартный воркфлоу SDXL рисует картинку.

### ☐ 3. Модели — урезанный набор (≈ 40 ГБ)

Те же модели, что на Mac, чтобы результаты были сопоставимы по смыслу.

| Модель                              | Для чего                                  | Примерно    |
| ----------------------------------- | ----------------------------------------- | ----------- |
| WAI-Illustrious-SDXL v17.0          | спрайты, style LoRA; тот же файл, что на Mac | ≈ 7 ГБ   |
| Anima Turbo + Aesthetic             | фоны, черновики                           | ≈ 8–10 ГБ   |
| Anima Base                          | обучение LoRA (позже, к шагу 8)           | ≈ 4–5 ГБ    |
| общие файлы Anima: энкодер Qwen3-0.6B, VAE Qwen-Image | для всех трёх Anima    | ≈ 1,5 ГБ    |
| FLUX 3 Image Klein, INT8 / FP8 + энкодер | генерация и правки по инструкции      | ≈ 10–15 ГБ  |
| BiRefNet + аниме-апскейлер (ESRGAN) | вырезание спрайтов, апскейл фонов         | ≈ 1 ГБ      |

- Qwen-Image 2.1 и NoobAI-XL **не ставим**: нет места, 16 ГБ RAM тесно, лицензии некоммерческие.
- Anima Base качаем только к обучению (шаг 8). После сравнения моделей проигравших удаляем.
- Точные файлы и версии сверить при скачивании (страницы моделей, Comfy-Org на Hugging Face) и
  записать в `msi/README.md`.
- **Проверка:** каждая модель рисует одну картинку 1024² в стандартном воркфлоу; время
  записать.

### ☐ 4. Генерация через API ComfyUI, сравнение моделей и замеры скорости

Аналог `mac/scripts/dt_generate.py`, чтобы Claude Code генерировал без интерфейса.

- ☐ `msi/scripts/comfy_generate.py`:
  - читает **тот же формат файла прогона**, что Mac: `prompts/bake-off.json` работает без
    изменений;
  - настройки моделей — `msi/scripts/models.json` (те же ключи, что на Mac: `anima-turbo`,
    `anima-aesthetic`, `flux3-klein`, `wai-illustrious`);
  - воркфлоу каждой модели в API-формате — `msi/workflows/`;
  - кладёт картинки в `content/` по тем же правилам ([content.md](../mac/content.md)), в `.json`
    вместо свопа — пик VRAM и RAM;
  - продолжает прерванный прогон.
- ☐ **Сравнение моделей** (перенесено с Mac): `prompts/bake-off.json` — 8 промптов (5 фонов +
  3 спрайта) × 4 модели (Anima Turbo, WAI-Illustrious, FLUX 3 Klein, Anima Aesthetic) × 2 seed =
  64 картинки → `content/benchmarks/<дата>-bake-off/`. На MSI можно и 4 seed, если 2 мало.
- ☐ Оценка 1–5: стиль semi-realism anime; фон (глубина, свет, перспектива); персонаж (анатомия,
  руки, лицо); артефакты; следование промпту. Итоги — `.claude/research/05-bake-off.md`:
  основная модель для фонов и для спрайтов, годится ли FLUX 3 Klein для аниме.
- ☐ Скорость из лога того же прогона → `msi/benchmarks.md`: секунды на картинку, пик VRAM,
  троттлинг на длинной серии.
- **Проверка:** один запуск из терминала рисует весь набор без участия человека; выбраны модели;
  оценки скорости из ресерча (Illustrious ≈ 10–20 с, FLUX 3 Klein ≈ 15–20 с) подтвердились или
  нет.

### ☐ 5. Сервер для Mac: Krita AI Diffusion

- ☐ Ноды, которые требует Krita AI Diffusion (список в [документации](https://docs.interstice.cloud)),
  и её модели (ControlNet, IP-Adapter — только под наши Illustrious и Anima, не всё подряд).
- ☐ ComfyUI с `--listen 0.0.0.0 --port 8188`; правило брандмауэра на 8188 **только для частной
  сети**. В интернет не выставлять: авторизации у ComfyUI нет.
- ☐ Постоянный IP MSI в локальной сети (резерв на роутере) — чтобы адрес в Krita не менялся.
- **Проверка:** Krita на Mac подключается к `http://<IP MSI>:8188` и делает «выделил →
  перерисовал» на одном фоне.

### ☐ 6. Claude Code ↔ ComfyUI через comfyui-mcp

- ☐ [comfyui-mcp](https://github.com/artokun/comfyui-mcp) — для генерации и правки воркфлоу
  словами. Скрипт шага 4 остаётся основным путём для прогонов: он воспроизводим.
- **Проверка:** из Claude Code по запросу словами рисуется фон по карточке локации.

### ☐ 7. Вырезание спрайтов и экспорт WebP

- ☐ BiRefNet в ComfyUI на спрайтах из шага 4. Критерии те же, что в плане Mac (шаг 6): волосы,
  полупрозрачные края, детали в цвет фона.
- ☐ `cwebp` (`winget install Google.Libwebp` или Pillow в скрипте): фоны — качество ≈ 85–90,
  спрайты — с альфой, near-lossless.
- **Проверка:** спрайт с прозрачным фоном открывается в webapp поверх фона без ореола.

### ☐ 8. Обучение LoRA

- ☐ Окружения: [OneTrainer](https://github.com/Nerogar/OneTrainer) (Illustrious) и
  [sd-scripts](https://github.com/kohya-ss/sd-scripts) (Anima, `anima_train_network.py`) — в
  `C:\AI\`, каждый со своим окружением. Конфиги — в `msi/training/`.
- ☐ **Технический тест** — не на рисунках Милы: LoRA персонажа по 15–20 картинкам одного
  персонажа из прогонов. 200 шагов на пробу, затем полный. Замерить время, VRAM, нагрев.
- ☐ **Боевая LoRA стиля** — на отобранном датасете `content/datasets/mila-style-v1/`, на
  Illustrious и на Anima Base, сравнить на одних промптах. Только после блокеров ниже.
- **Проверка:** LoRA подхватывается в ComfyUI, на тестовых промптах виден эффект.

### ☐ 9. VNCCS — конвейер спрайтов

- После сравнения моделей: внутри VNCCS генераторы Qwen Image 2.1 и FLUX.2 klein 9B — тяжёлые
  для 16 ГБ RAM и под некоммерческими лицензиями. Сначала проверить режим на Illustrious.
- ☐ Персонаж → 3 позы × 6 эмоций → прозрачный фон.
- **Проверка:** набор спрайтов одного персонажа в одном стиле, лицо узнаваемо.
