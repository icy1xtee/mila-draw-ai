# Замеры скорости — MSI Katana 17 B12VFK (RTX 4060 Laptop 8 ГБ)

ComfyUI portable v0.44.0, PyTorch 2.14.1 + CUDA 13.0, драйвер 610.78. От сети, MSI Center —
Extreme Performance, MSHybrid. Время — от отправки запроса в API до готового файла.

## Сравнение моделей `msi-bake-off` (07.11.2026)

[prompts/bake-off.json](../prompts/bake-off.json): 8 промптов (5 фонов 1344×768 + 3 спрайта
768×1344) × 4 модели × 2 seed = 64 картинки, `content/benchmarks/2026-11-07-msi-bake-off/`.
Весь прогон — **22 минуты** (21:28–21:50), от сети, без участия человека.

| Модель                       | Загрузка (разогрев 512²) | На картинку, медиана | Разброс     | 16 картинок |
| ---------------------------- | ------------------------ | -------------------- | ----------- | ----------- |
| Anima Turbo v1.1             | 9,0 с                    | **7,8 с**            | 7,6–8,0 с   | ≈ 2 мин     |
| FLUX 3 Klein INT8            | 13,5 с                   | **10,3 с**           | 10,1–13,0 с | ≈ 3 мин     |
| WAI-Illustrious v17          | 14,1 с                   | **18,1 с**           | 17,9–19,2 с | ≈ 5 мин     |
| Anima Aesthetic v1.1         | 17,4 с                   | **43,3 с**           | 43,0–43,6 с | ≈ 12 мин    |

- **Троттлинга нет:** первая и последняя картинки каждой модели по времени одинаковые, в том
  числе 16 картинок Aesthetic подряд (≈ 12 мин полной нагрузки).
- Оценки из ресерча подтвердились: Illustrious ≈ 10–20 с — 18 с; FLUX 3 Klein ≈ 15–20 с — 10 с,
  быстрее ожидания.
- RAM системы — пик 14,0–15,0 ГБ из 16 (больше всех у Aesthetic), свопа нет.
- На Mac тот же набор оценивался в ≈ 6,5 ч.

## Проверочный прогон `msi-smoke` (07.11.2026)

[scripts/comfy_generate.py](scripts/comfy_generate.py) с [scripts/smoke.json](scripts/smoke.json):
промпт `mark-room-night` из [prompts/bake-off.json](../prompts/bake-off.json), 1344×768, seed 1
и 2. Картинки и лог — `content/benchmarks/2026-11-07-msi-smoke/`. Полные цифры будут из
сравнения моделей (шаг 4 плана).

| Модель                       | Шаги, CFG, сэмплер                   | Загрузка (разогрев 512²) | На картинку |
| ---------------------------- | ------------------------------------ | ------------------------ | ----------- |
| Anima Turbo v1.1 (bf16)      | 10, CFG 1, euler/simple              | 11,8 с                   | **7,8–8,0 с** |
| Anima Aesthetic v1.1 (bf16)  | 30, CFG 4, er_sde/simple             | 20,1 с                   | 43–44 с     |
| FLUX 3 Klein (INT8 convrot)  | 16, CFG 1, euler/simple, shift ln 16 | 14,0 с                   | **10,2 с**  |
| WAI-Illustrious v17 (FP16)   | 28, CFG 6, euler_ancestral/normal    | 16,2 с                   | 18,1–18,2 с |

Память:

- **VRAM** по `nvidia-smi` у всех моделей одинаковая, ≈ 6,8 ГБ из 8: ComfyUI держит занятую
  память у себя и между запросами не отдаёт, поэтому цифра показывает только, что в 8 ГБ всё
  влезло. Чистая проверка (первый запуск, пустая карта): Anima Turbo — 6,1 ГБ, FLUX — 6,7 ГБ.
- **RAM системы** — 13,5–14,2 ГБ из 16 у всех моделей, вместе с ComfyUI, который держит
  выгруженные модели, и открытыми программами (VS Code, браузер). Свопа нет. Тесно не только
  из-за FLUX: перед долгими прогонами закрывать лишнее.

Настройки FLUX — из официального воркфлоу `flux3_klein_int8_t2i.json` (BFL), без prompt
upsampler. Aesthetic — из воркфлоу в карточке Anima.

## Для сравнения — Mac

Draw Things, [mac/benchmarks.md](../mac/benchmarks.md): Anima Turbo 1.0 8-bit S на 1344×768 —
54 с холодным, устойчиво 85–95 с; FLUX.3 [klein] 8-bit S на 1024² — ≈ 7,6 мин. MSI быстрее
≈ в 10 раз на Anima и в десятки раз на FLUX.
