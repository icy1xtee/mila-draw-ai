Проверено 07.11.2026 (`Win32_*`, `nvidia-smi`).

| Параметр   | Значение                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------ |
| Модель     | **Katana 17 B12VFK** (MS-17L5), BIOS E17L5IMS.30F                                          |
| CPU        | i7-12650H, 10 ядер / 16 потоков                                                            |
| GPU        | **RTX 4060 Laptop, 8 ГБ** (8188 МиБ), лимит до 105 Вт; плюс встроенная Intel UHD             |
| Драйвер    | NVIDIA 610.78, CUDA 13.3                                                                   |
| RAM        | **16 ГБ = 2 × 8 ГБ** DDR5 SK hynix HMCG66AGBSA095N (5600, работают на 4800). **Оба слота заняты**, максимум 64 ГБ |
| Накопитель | **Micron 2400, 512 ГБ** (NVMe, QLC), один том C:. Свободно **238 ГБ** (после чистки)       |
| Экран      | 17.3" FHD, ≈ 51 % sRGB — цвет проверять на Mac                                             |
| ОС         | Windows 11 Pro, сборка 26300                                                               |

Что из этого следует:

- 8 ГБ VRAM — базовый сценарий из ресерча: SDXL / Illustrious и Anima комфортно, FLUX 3 Klein
  в INT8 / FP8 влезает, обучение LoRA на SDXL и Anima реально.
- Рабочий стол рисует Intel UHD (режим MSHybrid / Optimus), поэтому видеопамять NVIDIA в покое
  пустая (0 МиБ) и вся достаётся генерации. Режим «только дискретная» в MSI Center не включать.
- **Диск — 512 ГБ, свободно 238 ГБ** (07.11.2026, после удаления одной игры). На урезанный
  набор моделей (≈ 40 ГБ), окружения Python (≈ 20 ГБ) и рабочий запас места хватает. Новый
  SSD не покупаем: лишних моделей не держим, освобождаем место по мере необходимости, держа
  ≥ 30 ГБ свободными.
- 16 ГБ RAM — тесно для FLUX 3 Klein и Qwen-Image с выгрузкой. Файл подкачки управляется
  системой — так и оставить.

## Роль

Основная рабочая станция:

- ComfyUI;
- пачки фонов и спрайтов (VNCCS);
- обучение LoRA на Illustrious и Anima;
- сервер ComfyUI для Krita на Mac и для Claude Code (через comfyui-mcp).

LoRA для больших моделей (FLUX 3 Klein, Qwen) проще учить в облаке.

## Что ставим

1. **Драйвер NVIDIA** — свежий. Проверить `nvidia-smi` в PowerShell: видна карта и её память.
2. **Git.**
3. **ComfyUI** — portable-сборка для NVIDIA из [репозитория](https://github.com/Comfy-Org/ComfyUI)
   в `C:\AI\ComfyUI\` (почему не Desktop — в [плане](../.claude/develop/msi/plan.md), шаг 2).
   Плюс ComfyUI-Manager для установки custom nodes. Python для наших скриптов — через `uv`.
4. **Custom nodes:**
   - [ComfyUI_VNCCS](https://github.com/AHEKOT/ComfyUI_VNCCS) и VNCCS-Utils (нужен для Pose
     Studio) — конвейер спрайтов. Есть установщик
     [VNCCS Easy Install](https://github.com/AHEKOT/VNCCS_Easy-Install) со всем сразу;
   - ComfyUI-Impact-Pack — FaceDetailer, перерисовка лиц и рук;
   - ноды, которые требует Krita AI Diffusion (список в
     [документации плагина](https://docs.interstice.cloud));
   - BiRefNet — вырезание фона.
5. **Тренеры LoRA:**
   - [OneTrainer](https://github.com/Nerogar/OneTrainer) — Illustrious / SDXL;
   - [sd-scripts](https://github.com/kohya-ss/sd-scripts) — Anima и SDXL.

## Настройки

- Работать от сети, MSI Center → режим **Extreme Performance**.
- 8 ГБ: ComfyUI без `--lowvram`, он сам выгружает лишнее в RAM. Генерировать в ≈ 1 МП и
  апскейлить.
- Windows: длинные пути включены (`LongPathsEnabled = 1`, 07.11.2026) — без них ломаются
  некоторые custom nodes и pip. Домашний Wi-Fi — профиль «Частная».
- **Доступ с Mac (Krita) и для Claude Code:**
  - ComfyUI слушает локальную сеть: `--listen 0.0.0.0 --port 8188` для portable или адрес
    сервера в настройках ComfyUI Desktop;
  - в брандмауэре Windows открыть порт 8188 только для частной сети.
  - У ComfyUI нет авторизации, поэтому в интернет его не выставлять.

## Апгрейд

- **RAM до 32 ГБ** — 2×16 ГБ DDR5 SO-DIMM (4800 или быстрее, работать будет на 4800). Стоят
  2×8, поэтому меняются **обе** планки. С 32 ГБ FLUX 3 Klein и Qwen-Image выгружаются в RAM без
  свопа на диск.
- **SSD — не покупаем** (решение 07.11.2026): живём в 512 ГБ, чистим по мере нужды.
