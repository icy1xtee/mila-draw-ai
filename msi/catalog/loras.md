# LoRA — что у нас есть и как ими пользоваться

Сгенерировано из [msi/catalog/loras.json](loras.json) скриптом `msi/scripts/lora_catalog.py doc` — правьте JSON, а не этот файл. Файлы лежат на MSI в `C:\AI\ComfyUI\ComfyUI\models\loras\<семейство>\`, в git их нет.

**Как это работает.** LoRA — небольшое дообучение поверх модели: стиль, детали, одежда, эффект. Работает только с моделью своего семейства (папка = семейство). В Mila Draw AI — блок «LoRA» под выбором модели: галочка, сила, слово-ключ добавляется в промпт само. Больше 2–3 LoRA сразу обычно портят картинку; две стилевые LoRA вместе дают кашу.

**Лицензия.** «Продавать картинки — да» значит, что автор на Civitai разрешил продавать сгенерированные картинки. «нет» — только для себя и этюдов: для ассетов продаваемой игры не годится.
