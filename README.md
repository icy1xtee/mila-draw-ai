# mila-draw-ai

Локальная генерация артов для визуальной новеллы «On the Other Side»: фоны и спрайты персонажей в
стиле semi-realism anime. Всё работает на своих компьютерах, без облачных сервисов. Облако —
разве что для обучения больших LoRA.

Сама игра живёт в соседнем репозитории
[on-the-other-side-webapp](../on-the-other-side-webapp). Готовые арты уходят туда, в
`src/assets/`, в формате WebP.

## Статус

**Этап ресерча.** Модели, инструменты и роли машин выбраны, ничего ещё не установлено.
Следующий шаг — установка на обе машины и сравнение моделей на одном наборе фонов и спрайтов
(план в [.claude/research/04-pipeline.md](.claude/research/04-pipeline.md)).

## Как идёт работа

1. **Идея и черновик** — на Mac (Draw Things, быстрые модели).
2. **Генерация** — на MSI в ComfyUI:
   - фоны: Anima или Illustrious + LoRA стиля → апскейл до 2560×1440;
   - спрайты: VNCCS — позы → костюмы → эмоции → прозрачный фон.
3. **Правки** — FLUX 3 Image Klein по инструкции или Krita: выделил область → перерисовал. С Mac
   Krita работает через ComfyUI на MSI.
4. **Доводка** художником и проверка цвета на Mac.
5. **Экспорт** в WebP → `on-the-other-side-webapp/src/assets/`.

Claude Code может управлять ComfyUI на MSI через MCP ([comfyui-mcp](https://github.com/artokun/comfyui-mcp))
и брать описания персонажей и локаций из «библии» в этом репо.

## Что не кладём в репозиторий

- **Веса моделей.** Они живут в папках Draw Things и ComfyUI, каждая по 5–25 ГБ.
- **Сгенерированные картинки.** В игру уходят только финальные, в репозиторий игры.
- **Датасеты для обучения.** Особенно работы художника: права на них — отдельный вопрос.
